## 文档维护约定

- 操作规则以使用说明书为主，字段规则、接口与数据包各自保留一份规范；其他文档引用对应规范。
- 发布结果写当前验收记录，更早的过程按 `history/YYYY-MM/`归档并登记索引；不把历史题量、测试数或版本号当成当前结果。
- 文档之间使用相对链接；移动文件同时检查入站链接、出站链接与标题锚点。运行 `npm run docs:check`检查所有当前及历史 Markdown。
- 内置手册引用的源文档和根 README 变化会影响下次 Web／Android 构建。文档整理不直接重写已有软件包；重新发布时按候选提交、资源清单和校验和核对。
