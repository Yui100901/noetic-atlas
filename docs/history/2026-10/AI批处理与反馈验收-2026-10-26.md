## 已实现

| 模块 | 行为 |
| --- | --- |
| AI可靠性 | 真正开始模型调用后的失败／取消进入处理记录，无可应用结果；诊断区分HTTP鉴权／限流／服务错误、超时、空响应、封装／正文JSON、截断和结构字段错误，提供阶段、耗时、字节、结束原因、调用明细及建议 |
| 历史与持久化 | 按类型／状态／任务筛选，数据库计数分页后读取当前页；重试前失败记录保留；Android失败业务回滚后只重放安全失败审计，磁盘失败返回507并回滚 |
| 教材多轮处理 | 多文件、本机PDF选页与分块；确认创建任务后先逐块AI总结，再选择单块或全部生成；每请求最多5块，页面多轮推进 |
| 预算与恢复 | 每块最多50题，任务最多2000题，可按所选块数下调每块题量；保存每块实际题量，成功块跳过，失败块可重试；重新打开／进程中断后能继续 |
| 预览与入库 | 本地可信文件／页段出处、跨批精确重复和素材引用检查；可选题及编辑JSON，确认后原子新增待审核题，重复确认拒绝 |
| 质量反馈 | 单题／组合叶题反馈，记录原内容指纹；待核查／已确认未解决反馈产生疑似标记，兄弟小题不串标，不改变题目发布状态 |
| AI反馈复查 | 站内索引检索有限候选，显示选项／答案／材料并逐条分析反馈是否成立；批量允许部分成功，失败原因及历史保留，用户显式处理反馈 |

入口与具体限制见[使用说明书](../../使用说明书.md)。来源、诊断与处理说明放在管理区，不塞入学习题干。

## 数据与剩余边界

工作库现存22个业务表测试前后逐行SHA-256及数量完全一致：31,811题、226题集、196附件及现有作答、笔记、复习和配置全部保留。`ai_import_jobs`与`question_feedback`的新数据仅存在于隔离测试库，本机旧后台未被替换。完整指纹在`test-results/ai-reliability-batch/workspace-before.json`与`workspace-after.json`。

本轮未生成正式签名APK、Windows便携包或Docker镜像，也未进行Android真机安装／系统权限／后台生命周期测试。新接口和页面需重启本地服务后使用。

教材支持的是按真实页段／段落分块后由AI总结主题，不保证自动识别原书全部章节；不支持OCR，复杂表格／公式／缺图仍需核查。站内候选是有上限的关键词／索引检索，不保证发现所有重复，也没有联网核验。AI复查不等同事实已被证明；完整修订版本、题集升级和全库语义去重仍为后续扩展。

私人教材任务及AI历史随完整SQLite搬迁，普通JSON不包含；用户反馈和处理结论随可信JSON搬迁，普通内容分享不带私人反馈。自动重试不保证供应商只计费一次；本地确认入题、应用评分与处理状态均保留独立幂等／版本边界。
