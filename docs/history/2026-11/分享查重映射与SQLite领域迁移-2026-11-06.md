# 分享查重映射与 SQLite 领域迁移

日期：2026-11-06。仅调整源码、文档和隔离验收夹具，没有操作工作数据库、已安装应用、已有服务或真实 AI 凭据；未提交代码或生成发布包。

## 内容导入与分享

- 含题目的数据包自动附带 `metadata/question-hashes.json`，按算法版本、数据文件摘要和题目顺序绑定；导出预检也计算摘要文件开销。
- 导入默认查重，可显式关闭。关闭时跳过题目索引、候选查找及合题，不跳过文件完整性、业务结构、引用及审核校验，冲突题号另存。
- 相似候选按领域筛选，分类间仍比对，无领域时保守兜底；完全相同内容仍做低成本全库摘要查询。
- 分享包支持来源领域、分类、标签映射或改名创建，先映射再查重。修改选项使旧预览和处理决策失效。
- 摘要是缓存提示，命中仍比较规范学习内容；未命中、未知版本或缓存失效时回算。重新生成清单的伪造摘要也不能造成错误合并或绕过查重。
- 修复跨领域批量导入时，其他领域候选挤掉同领域相似候选的问题。普通批量新增、AI 结果及教材分批导入共用查重选项。

## SQLite 迁移

- 系统配置的内容导入导出合并为“数据与迁移 → 迁移”。普通按领域分享移至“分享与导入 → 按领域分享”。移除独立配置迁移界面及其专用 UI 验收脚本；旧底层协议接口仍由已有回归保护。
- 支持整个学习站或多个指定领域，先展示计数、必要依赖与范围说明，导出原始 `.sqlite` 或包含数据库、manifest 和迁移说明的 ZIP。
- 迁移范围包括相关题目、资料版本和附件、完整题集、整次作答及答案、独立单题历史与统计摘要、笔记、草稿、FSRS 卡片及事件链、质量维护记录及 AI 处理历史。
- 跨领域题集和历史作答保持完整，保留必要引用题；必要依赖不会反向拉入全部无关题集。没有归属的任务和草稿由整体迁移保留。分类标签与配置结构随副本保留；领域副本关闭自动推题。
- 已删除原题、已清理整卷时，仍按保留的历史快照识别领域并带走独立答案、统计摘要及 FSRS 链。
- 只在一致性副本中裁剪、校验、脱敏、重建派生索引及压实数据库，避免被排除正文或 AI 密钥留在空闲页。源库不变，源数据变化会使预览失效。
- Android 支持 ZIP 与原始 SQLite 文件，继续执行隔离验证、显式确认、替换前备份和失败回滚；电脑使用停服替换独立数据库的恢复流程。SQLite 迁移不作为内容合并。
- 旧 SQLite 下载入口复用同一验证与脱敏导出服务，避免维护两套副本逻辑。

## 验收范围

隔离回归覆盖包摘要、伪造缓存、默认与关闭查重、分类映射、分页及预览失效；服务端及真实 SQL.js 覆盖整体／领域迁移、跨域依赖、独立学习历史、原文及附件、密钥清除、删除内容字节残留、恢复与回滚。

浏览器专项包括 SQLite 迁移、领域分享、导入选项、数据包读写、旧入口跳转、配置草稿保护、相似题核查及 AI 导入／教材／草稿／组题。对 320、390、1440 像素截图检查，修正了导入统计表格的间距；原生恢复 UI 使用隔离桥接夹具，不代表新 APK 的设备验收。

最终全量测试 1,357 项：1,353 通过、4 项可选实际内容检查跳过、0 失败；生产构建及配套检查通过。机器生成日志保存在忽略的 `test-results/current-task-*.log`、各专项报告及 `test-results/qa-runs/`。首次高并发运行的桌面启动检查遇到服务就绪超时，单独复测通过；最终全量运行降低文件并发，保持原产品与测试超时阈值。
