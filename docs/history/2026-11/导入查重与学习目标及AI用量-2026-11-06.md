# 导入查重、时间目标与AI用量验收

日期：2026-11-06。实现普通内容导入查重与差异确认、可选时间预算和周目标、供应商实际AI用量统计。软件版本号与发布数据包协议不变。

## 使用入口与规则

- 新题ZIP、分享ZIP、AI单次转换和教材分批确认共用查重。完全相同的学习内容自动复用；相似题明确选择保留原题、覆盖或保留两者。支持分页、批量选择和内联差异查看，图片题可在落库前预览。修改源输入后重新核查，预览过期或题库变化会拒绝旧确认。
- 覆盖保留本地题号、审核状态、学习记录和旧卷面，并记录修订。选择保留原题会跳过导入版本及其来源；完全重复复用则可补充来源。组合题小题标准跟随验证后的编号映射，无法安全映射或合题造成标准冲突时整包拒绝，不猜测覆盖。
- 新增题继续待审核。可信迁移及SQLite恢复保持原身份与历史关系，沿用已有迁移语义，不引入题库版本账本。新题ZIP整包上限50000题，独立批量接口仍为500题，文件字节限制同时生效。
- “系统配置 → 每日推题”可开启工作日／周末分钟预算，单独设置周目标。时间安排使用逐题有效计时样本或题型估计，优先复习，保留生成快照；未开启时继续原分值计划。题集计划入口、计划详情和设置页可查看周进度及切换周范围，进行中与正式提交时间分开，缺失历史不估填。
- “AI工作台 → AI处理记录”按日期、模型、任务与状态筛选并汇总Token、缓存和推理明细。只统计实际返回值，区分0、未知及部分用量；兼容流式用量帧、失败和取消，不重复累加累计帧或缓存明细。不加入金额或预算。

操作细节见[使用说明书](../../使用说明书.md#导入查重与近似题核查)与[数据包格式](../../数据包格式.md)。

## 实现边界

查重使用可重建的增量内容索引、有限候选和按需详情读取。查询通过Kysely及既有数据库适配层，SQLite触发器与驱动操作局限于数据库目录；移动WASM复用业务模块。确认后统一事务，失败不留下部分题目、依赖或题集。未引入新的运行依赖。

AI用量汇总仅读取审计元数据，不为统计加载完整模型回答。流式服务明确不支持用量选项时仅回退一次，保留两次调用记录；缺失值不伪造成0。JSON内容迁移继续排除私有AI处理记录，SQLite完整备份恢复保留记录，密钥仍按既有规则处理。

近似候选不保证发现所有语义相似题；没有自动全库删题或修改既有学习记录。时间估计用于安排，不会改变考试倒计时或强制交卷。

## 规模测量

本机Node 24.13.0、内存SQLite、30000条合成已有题，每轮10000条输入，未读写工作题库：

| 场景 | 耗时 | 结果 |
| --- | ---: | --- |
| 首次完全重复检查，包含初次索引构建 | 4196ms | 10000条复用，候选详情比较0次 |
| 索引就绪后再次完全重复检查 | 914ms | 10000条复用，候选详情比较0次 |
| 不重合的全新题 | 773ms | 10000条新增候选 |

另一个近似措辞样本耗时1165ms，实际候选比较199790次，未执行已有题数与输入题数相乘的全量比较。此处是特定短题合成输入的后端预览测量，不代表附件导入耗时或Android内存容量。进程RSS含题库、输入与连续测量对象，不能作为手机容量结论。
