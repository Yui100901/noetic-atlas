# 认知星图 2.0

本文件保留开发期当时的版本说明，不代表正式发布或兼容承诺。首次正式发布基线已重新定为 [1.0](../../版本说明-1.0.md)，下文版本号和功能描述按原始记录保留。

2.0完善多领域学习、内容编辑与数据迁移流程。Web、免安装Windows桌面端和Android继续共用学习规则，软件采用空题库安装，领域题库单独提供。

- 专注复习支持逐题回忆、核对与评级、心答或实际作答、暂停续练及总结；多领域计划按权重或固定分值安排新题与复习，结合FSRS到期队列追踪每日任务。
- 题库与题集共用阅读组件和AI助手，独立区分AI解析与回答评价；题集内保留上下题顺序和返回位置，统计入口统一为可按日、周、月查看的学习分析。
- 原题与组合小题可填写判题要求，题集默认沿用并允许覆盖或清空；手动、随机及AI推荐组题均可在创建前完整预览、调整顺序、分值与逐题标准，历史作答保留当时快照。
- 词汇卡提供专用编辑、读音与词性来源、独立逆向提示及允许答案，双向预览复用实际判分规则；概念卡和词汇卡分别保留顺逆向复习状态。
- 教材原文与题目双向关联，支持Markdown段落定位、PDF页码阅读、固定引用版本及AI出题关联；公式与专业表达提供本地LaTeX排版、模板、语法提示与导出。
- 内容维护加入独立题目编辑草稿、修订历史、字段对照和恢复；质量扫描覆盖判题标准格式与双向规则，反馈和扫描证据按题汇总、逐项处理。AI评分继续以原题、有效判题要求和实际回答为依据。
- 系统配置按外观、练习、复习、草稿历史、文件资源、AI、数据迁移七类组织，右侧使用标签页；分区切换保留草稿，保存、导入冲突与保留数量调整有明确反馈。
- 在线按领域导出支持单选、多选、合并JSON及分领域ZIP，补齐分类祖先、标签和图片；可信迁移保留审核状态，分享新增题仍需审核。完整JSON和SQLite备份保留编辑草稿与修订，普通分享不携带私人维护记录。
- 数据维护提供健康检查、清理预览、索引重建及分级学习重置；启动入口复用未变化的成功构建，按规模分页加载和检索，降低重复编译与整库读取。

各端版本读取`package.json`，Android 2.0的`versionCode`为20000；后续更新沿用正式签名，升级前请备份原数据库。软件仅附干净基础配置，AI默认关闭，不含个人端点、密钥、工作数据库、学习记录或题目。发布脚本只构建软件；`npm run content:domains`独立导出题库，默认输出`artifacts/domain-packs/v2.0/`。

具体测试结果与设备验证范围见[验收记录](../../验收记录.md)；当前使用、内容导入与更新步骤见[使用说明书](../../使用说明书.md)和[发布与部署](../../发布与部署.md)。[1.5.0开发期记录](./开发期版本说明-1.5.0.md)同样保留为历史说明。
