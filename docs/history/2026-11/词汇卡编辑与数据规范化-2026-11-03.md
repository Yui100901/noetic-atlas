# 词汇卡编辑与数据规范化

日期：2026-11-03。语言词卡继续使用现有题目身份、答案与解析，不另建一套词汇库。操作入口为新建简答题的“作为词汇卡”，或现有词卡的“编辑题目”；日常操作见[使用说明书](../../使用说明书.md#下载导入与审核)。

## 本次功能

- 专用编辑：英语／日语、主词、词性、读音增删及可选出处、独立逆向提示、允许答案、逆向开关和匹配规则。
- 词条更名只替换原主词答案，保留其他人工别名并提示核对；显式生成标题与题干，可撤回该次生成。
- 释义使用原参考答案，例句、搭配、关联词和辨析使用原解析；不会自动重写正文或正向判题标准。
- 双向预览默认收起答案；逆向隐藏主词、读音、例句与详细说明，可试填并使用实际客观评分逻辑核对。
- 保存时清理空答案、重复项与无意义首尾空白，并补入精确主词；设置保留首尾空白时尊重已录入的答案空白。
- API、编辑器、导入、AI建议和质量扫描共用词卡契约。未提供读音或来源合法；普通释义中的方括号合法，实际答案链接与泄露提示会阻止启用逆向。
- 独立提示重复检查在编辑后延迟350毫秒执行，只查询同语言的计数和最多5条头部信息，使用绑定查询和表达式索引；取消旧请求并忽略迟到结果。
- AI编辑支持词卡完整字段建议，禁止模型改换语言、主词或新增词卡身份。建议逐条应用／撤回，独立校验；来源正文和学习状态不会被模型直接写入。
- 关闭逆向后仍可正向练习。新逆向作答及安排受限，专注复习与计划不再选择该方向，已存在的记忆和历史保留。题集抽样若选中关闭逆向的卡片，明确提示失败，不默默跳过。

可选性与具体字段规则见[题目字段与质量规则](../../题目字段与质量规则.md#词汇卡字段)。没有新增持久化的逆向评分文本，展示规则从本次允许答案与匹配设置派生。

## 维护命令

在项目根目录执行，默认只生成计划。对正在使用的题库应避免同时编辑；内容指纹不一致时会中止写入。

```powershell
node --import tsx scripts/content/vocabulary/standardize.ts --plan
node --import tsx scripts/content/vocabulary/standardize.ts --apply
```

可用`--database`指定数据库、`--report-folder`指定报告目录。再次执行应为0改动。新建或导入词卡仍按正常待审规则处理，脚本不会替用户通过审核。
