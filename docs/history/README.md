# 历史专项与核查报告

本目录按年月保留开发期验收、性能测量、界面巡检和工程核查。题量、测试数、已知限制和后续建议对应当时状态，不代表当前交付。产品以 [1.0](../版本说明-1.0.md)作为首次正式发布基线；此前 1.x／2.0 编号和原 3.0 计划不构成正式版本兼容承诺。

现行操作见[使用说明书](../使用说明书.md)，当前结果见[验收记录](../验收记录.md)，发布与升级按[1.0 发布清单](../1.0发布清单.md)和[发布与部署](../发布与部署.md)执行。返回[文档导航](../README.md)或[项目说明](../../README.md)。许可原文保留在 `docs/licenses/`，内容处理快照见[题库整理记录](../题库整理记录.md)。

## 归档约定

- 当前验收只记录当前基线，更早流水按月份迁入本目录；专项报告保留原测量口径，不以新结果覆盖旧事实。
- 原验收记录的历史章节完整保存在各月的“开发期验收流水”，原有跨文档锚点随归档同步更新。
- 新报告使用 `docs/history/YYYY-MM/` 并登记本页，日期版本说明明确标为开发期。
- 链接使用相对路径；移动文件后运行 `npm run docs:check`，同时检查入站链接、出站链接和标题锚点。
