## 开始使用

电脑启动学习站后打开本地网址，默认是 `http://127.0.0.1:4317`。停止服务不会删除SQLite数据库。Android安装包在首次打开时初始化自己的本地数据库，日常学习无需电脑服务。

左侧按知识题库、题集与练习、资料库、分类与标签、AI工作台、分享与导入组织。系统配置位于导航下方。手机通过左上角菜单打开导航。

首次安装没有预装题目、领域、分类或标签，只有干净基础配置。可新建内容或选择领域题库包导入。安装新版不会重灌或覆盖原来的题目、审核状态和学习记录。

题目编辑或看题笔记尚未保存时，返回、切换页面、浏览器后退或开始自测前会提示确认；取消离开会保留输入。题集与资料库的筛选、分页和每页数量可随查看／编辑返回恢复，避免反复重新查找。处理中暂不允许关闭的弹窗，可先等待完成或使用“取消本次处理”；关闭后恢复原入口的键盘焦点。

知识总览下方的“用户使用手册”卡片和右上角帮助按钮可打开应用内手册。手册随网页、Windows桌面版和Android资源一起打包，无需联网，可按目录跳转或搜索章节内容。字段规则等相关文档可在应用内继续阅读；外部参考网站在新窗口打开，需要网络。手册随应用版本更新。

## 领域分类标签与题集

| 概念 | 用途 | 示例 |
| --- | --- | --- |
| 领域 | 学科或独立知识范围，可自由新增 | 计算机与软件、语言、驾驶、化学、医学与药学 |
| 分类 | 某个领域下的多级树，表达知识归属 | 后端→语言→Go、通用基础→操作系统 |
| 领域标签 | 隶属于一个领域的交叉主题 | 并发、事务、内存管理 |
| 全局标签 | 跨领域的学习方式或用途 | 概念题、应用题、代码阅读、排错分析 |
| 题集 | 按目标整理题目及快照，可直接浏览、练习、考试和导出 | 课程基础、词汇表、某考试专题 |
| 内容属性 | 区分通用内容与个人专项内容 | general / personal |

个人专项可用于个人学习目标、课程专题、工作经验或项目复习，按普通分类、标签和题集组织。

分类是树，题目可以属于多个分类；同题可以进入多个题集，题集保存各自的版本快照。收藏绑定整道原题；普通题的笔记与复习进度绑定原题，组合题各小题分别记录。删除题集保留原题、历史作答和独立错题记录。旧版独立“题库集合”已合并：旧数据库启动或旧JSON导入时会自动转成题集，保留名称、顺序和全量题目；含未发布题的题集先归档，审核后再恢复。领域主题标签需与题目所属领域相匹配；学习方式标签可以全局使用。

难度D1—D4、深度L1—L4、常见度F1—F3和题型使用结构化字段，不重复做普通标签。F表示在指定学习或考试范围内的经验估计，不是统计概率；普通学习内容可以选择未标常见度。

领域、分类和标签可以在管理页添加或调整。被题目、资料、子分类、题集组织或筛选条件引用的项会受到删除保护。调整分类所属领域也会校验已有引用。

药物卡片以“医学与药学”为主要学习领域，按治疗类别组织；同一题号另引用“化学／药用化学物质”分类。修改答案、写笔记和标记掌握程度都作用于同一题目，两领域查询到它时不重复计入全库总数。化学中的无机物、有机物、食品组分和材料继续按其知识归属分类。

通用标签“可能失效或过时”用于历史来源、法规、平台版本及明确依赖时间或地区的监管结论；按题目实际内容、适用版本及来源证据判断，不因属于医学与药学就统一添加。基础概念、作用机制、医学统计原理不会仅因出现“禁忌”“警示”或“阈值”而被标记；药物卡保留“药物信息需复核”及来源核验日期。“已确认含失效内容”用于已有现行依据证明冲突的条目，解析列出具体原因和来源。另有“版本相关”“含AI生成内容”“资料待补充”“考纲归属待核验”等标记。题库筛选可直接选这些标签；发布状态与内容风险标记相互独立。

## 题目管理与审核

题库管理分为两个入口：**审核管理**确认新题或待审题能否进入正式题库；**质量管理**统一接收用户反馈和扫描发现，持续核查、修正与提升题目。质量处理不会替代准入审核，已审核题仍可存在待核查问题。

### 题型和组合题

支持判断、单选、多选、填空、简答、论述/写作六种独立题型。组合题是公共材料和多个独立小题的组织结构，小题可以混合这六种题型。比如一段程序配判断、输出填空和设计说明；英语阅读等未来内容也可使用同一结构。

填空按空位顺序匹配，可配置答案别名、大小写、首尾空白规则；所有空位匹配才算整题正确。多选须所选集合完全一致，暂不提供部分分。论述类独立于简答，避免把长篇写作都挤入短答字段。

组合题整组选题、逐小题作答和判分。公共材料展示一次，各小题保留独立答案与解析。题集可保存超过500个作答项，完整内容不会截断。每次练习或考试最多500个展开作答项，组合小题也占额度。大型题集开始前需明确选择本次题量与顺序／随机方式。

组合题在看题页面按小题保存掌握程度、笔记、最近复习和下次复习日期。复习甲小题不会把乙小题标为已复习；“收藏整组”仍作用于整道公共材料。旧版整组笔记与复习事件保留在“整组历史与公共笔记”，不会自动复制成每道小题的完成记录。已删除或改变题型的小题仍可读旧快照，但不能把旧进度写到其他小题。

### 新建和编辑

题库顶部可单题新增或批量导入。编辑器支持Markdown题干、选项、答案、解析、来源以及分类标签。题干和组合小题可上传插图；答案、解析等Markdown字段也能引用已上传图片。编辑、保存、归档、永久删除等主要操作放在页头。参考来源可以留空，空来源不会阻止保存、审核或练习，也不会产生质量问题；填写来源时仍需使用支持的地址格式。

删除选择题中间选项后会连续重编号，正确答案跟随原选项内容；组合小题行为一致。答案和解析正文中的选项字母请核对，系统不盲目替换自由文本。

编辑页靠前显示本题及小题的质量问题，用颜色及文字区分待核查、已确认、需重查、已解决和已忽略状态。每项卡片都有自己的处理状态、备注和保存按钮；证据及AI复核可另行展开。初次进入时，有待处理问题默认展开；未发现问题或全部问题已处理时默认收起，仍可手动展开。具体问题链接会自动展开并定位该项。正文未保存或其他页面已更新题目时，会先阻止质量处理。编辑区相邻卡片在桌面保持20px、手机保持16px间距。

从审核或质量管理进入编辑页时，默认展开题干、选项、答案及解析预览，不显示学习情况、历史作答、掌握度或学习笔记。保存默认留在编辑页，可接着重扫和处理问题；顶部“返回审核管理”或“返回质量管理”恢复进入前的筛选与分页。普通题库编辑仍保留原有返回流程。

单题查看页保留“收藏”和主要练习入口，分享、编辑、归档、删除集中在“题目操作”下拉菜单。菜单支持键盘选择、Escape和点击外部关闭，归档与永久删除继续使用原有确认和引用保护。

新建题默认待审核，可先存为草稿；普通新增入口不会因为JSON写了published就直接发布。已有已发布题编辑时可以保留原状态，也可退回待审核重新检查。

### 查找相似题和AI推荐近似题

在题库单题页或题集内看题时，使用“查找相似题”展开当前页的候选面板。组合题可以针对所选小题查找。普通搜索无需开启AI，可使用自动关联或输入关键词，结果仅包含本机题库的已发布题，排除当前原题；支持分页、每页数量和展开预览。查看候选可另开题目页，原看题页和题集位置保留。

按钮下拉中的“AI推荐近似题”会从检索到的已有候选中推荐，并说明相同知识点、解题方法或变式关系；可以补充推荐要求。确认后将发送原题、所选小题及有限候选内容给配置的模型，不发送学习笔记或作答历史。界面显示处理进度，可取消；成功或失败留在AI处理记录中。没有候选时可调整搜索词，不会凭空生成新题。

近似性是检索或模型判断，不代表题目答案已核验，也不保证覆盖题库中全部语义相近题。此入口只在阅读时显示；练习、考试作答期间不显示，词汇逆向阅读须先揭晓答案。题集旧快照对应的原题已删除时，不能基于该原题继续检索。

### 批量新增和外部修改

批量新增页可下载JSON模板和分类、标签ID参考，模板涵盖六种题型及组合题。每批1—500题；新增全部进入待审核，既有题号冲突或任何一题校验失败时整批回滚。审核通过后可通过题集编辑器加入所需题集。

要修改已经存在的待审核题，请在审核页选择题目并导出“待审核JSON”，保留题号、pending状态和原updatedAt版本，修改后回导。此入口不新增题，不覆盖已发布题；更新成功仍待审核。不要用批量新增模板替代待审核修订格式。

### 人工和AI审核

审核列表默认展开题干、选项、参考答案和解析。点击题目标题或“详情与编辑”直接进入编辑页，核对内容并及时修正。审核编辑页直接展示答案预览和前置质量问题，避免进入学习或答题流程。正文有修改时，先保存，再确认审核。

待审核题的编辑页可“确认审核通过”或“退回草稿”，完成后返回原管理列表；未作审核决定时也可直接返回，原搜索、领域、页码及每页数量保留。保存正文与审核发布分别确认，不会因保存题目自动发布。

人工审核可单题确认，也可跨页选择批量通过或退回草稿。系统核对选择时的更新时间，任一题已被修改则拒绝整批操作。

AI审核需先在系统配置中启用AI。提交选中待审核题后，模型分别给出无误、需修改或不确定；可选择让本次明确无误的题通过审核。缺图、资料不完整、模型输出冲突或版本变化时，不自动发布。有错的题保留待审核，并可检查、应用AI修订建议后重新审核。AI审核不是正确性的保证，重要内容仍应核对原始来源。

### 题目反馈与疑似标记

在单题详情的操作菜单选择“反馈题目问题”，或在题集阅读／组合小题的查阅区域反馈。选择答案、解析、歧义、重复、时效、缺内容或其他类型并说明原因。反馈针对原题和可选小题，记录反馈时的内容指纹；快照与当前原题不同会提示，原题已删除时不能提交。逆向词卡未揭示答案前隐藏相关反馈信息，作答期间不展示核查提示。

每次提交反馈都会进入**质量管理 → 待核查**。同一道题可以保留多条反馈，各自保留说明、证据、AI复核结果和处理记录，不会因题号相同就合并丢弃。在质量管理中处理，无须再进入独立的反馈核查页面；详细操作见[全库内容质量管理](#全库内容质量管理)。

有待核查或已确认未解决反馈的题显示“疑似有问题”。组合小题分别计数，某个小题的反馈不会给兄弟小题加标记；整题反馈会影响整组。质量处理状态与对应反馈同步，未解决反馈关闭后更新疑似标记，处理记录仍保留。该标记和处理结论不会改变题目的发布审核状态、旧成绩或复习安排。

反馈及处理结论随可信JSON备份／合并迁移和完整SQLite恢复保留；普通内容分享不默认包含私人反馈。删除原题后仍可保留反馈记录，来源不可用或已变化会明确显示。

### 归档和删除

归档隐藏原题并停止新组题，保留内容和引用。永久删除会移除原题及对应整题、小题学习状态和旧复习动作；仍被现存卷（包括归档卷）引用时会拒绝删除。已经形成的历史作答和独立错题保留自己的快照，之后修改或删除原题不会重算旧成绩，也不会替换错题内容。FSRS卡片与回忆反馈独立保留供统计和迁移，原题不可用后不再进入可复习队列。

## 全库内容质量管理

字段必填性、默认值和各题型判分要求统一见[题目字段与质量规则](./题目字段与质量规则.md)。

### 一个入口处理反馈和扫描问题

在“知识题库 → 题库管理 → 质量管理”进入，或打开 `#/content-quality`。题库管理只区分审核管理和质量管理；反馈核查不再是独立管理入口。旧的 `#/question-feedback` 地址会定位到统一质量管理，并保留题号或反馈定位信息。

质量管理按“题目 → 问题项”组织，同一道题在主列表只出现一次，组合小题的问题也归在原题下。主页面以题目和题下的问题简要列表为主，逐项显示描述、用户反馈／规则扫描来源和状态颜色；需要修改或核查时进入编辑页。概览区分题目数与问题项数。一题多条用户反馈逐条保留；扫描重复命中相同内容和规则时复用原记录。扫描不会关闭用户反馈或覆盖人工结论。

### 查看证据和处理问题

主列表提供关键词、状态及来源筛选，领域、严重程度和规则收在“更多筛选”中，支持按题目分页及调整每页数量。题下问题按当前可见题目逐步加载，超过一页可单独翻页。主列表的筛选只决定哪些题符合条件，题下仍展示全部来源的问题，方便一起核查。

题目标题及“详情与编辑”进入编辑页；具体问题旁的“详情与处理”还会定位该项。编辑页靠前的彩色质量面板显示问题描述、来源、状态及小题位置，选中后核对反馈原文、扫描证据、AI建议和已有对比候选；原题、选项、参考答案与解析预览默认展开。处理完可留在编辑页继续修改或核查其他项，再返回原质量列表，筛选、页码和每页数量保留。旧问题或反馈链接同样定位到编辑页相应问题项。

原题已删除时，质量列表仍保留问题记录并提示不可编辑；当前题面已变化时，会提示旧证据需要重新核对。

每个问题项独立保存待核查、已确认问题、已解决、已忽略状态；失效的扫描证据另显示“需重新检查”。在对应卡片选择“本项处理状态”，填写“本项处理依据 / 备注”，点击“保存本项状态”。处理一项不会关闭同题其他项；保存引起的列表刷新也不会清空其他项尚未保存的状态选择和备注。确认、解决或忽略需填写本项依据并检查该项版本；空备注时点击保存会明确提示并定位备注框，不提交状态更新，也不共用其他问题的备注。勾选具体问题项后，打开“扫描与批量工具”处理，可跨题目、跨分页选择最多100项（AI复核最多20项），不隐式选中整题全部问题。反馈关联的状态同步更新，不需要在两个页面分别关闭。参考来源为空不属于质量问题，也不需要补一个来源后才能解决其他问题。

详情右侧“AI复核本条问题”会结合本题、参考答案、问题证据及站内候选给出建议，进度、结果和失败原因在当前详情内显示。需先启用AI辅助；原题或候选已变化、原题不可用、规则停用或问题已处理时，会说明暂不能复核的原因。AI建议不代替人工处理状态。

各问题卡片分别选择处理状态并保存：

| 本项处理状态 | 保存的含义 |
| --- | --- |
| 已确认问题 | 反馈或提示成立，题目仍待修正 |
| 已解决 | 已修正并核对当前题目；原题改动后需要先重新扫描 |
| 已忽略 | 经核查，本次反馈或规则提示不成立／无需处理 |
| 待核查 | 将已经处理的问题重新打开 |

每项卡片显示当前状态、更新时间和本项保存结果。证据区域负责查看反馈、候选及AI建议，状态在对应卡片中单独保存。版本冲突或保存失败会在原处说明，可刷新本条证据后再操作。保存状态记录核查结论，不会自动修改题干、选项或答案。

在编辑页可查看本题和组合小题的统一质量问题。从管理页进入时保存默认留在编辑页；普通编辑也可使用“保存题目并继续处理”。修改正文后先保存，再重新检查并填写处理依据。未保存的正文、其他页面造成的版本变化都会阻止陈旧操作；处理状态不会自动修改答案或发布审核，也不会重算历史卷面。

编辑有未处理质量问题的原题时，如果相关处理状态仍未改变，保存前会出现一次“保存前核对质量问题”提醒，可选择返回编辑、保留状态并保存，或保存并继续处理。返回编辑不会写入；保存并继续处理会留在编辑页供重扫和核查，不自动标为解决。题目没有修改、没有未处理问题，或相关状态已明确变更时不重复提醒；同题其他尚未处理的反馈仍分别核对。提醒会检查全部分页，AI仅更新证据时间或扫描将问题标为失效不视为人工处理。

### 规则扫描

在质量管理中展开“扫描与批量工具”使用规则扫描、历史记录及批量处理。“新建并开始扫描”默认检查全部发布状态，可选领域、分类（含子分类）、标签、题型及审核状态。页面每批扫描100题并显示进度、发现数及新增数；可在当前批次完成后暂停，再通过当前进度或扫描历史继续。离开页面停止发起后续批次，已完成批次不丢失。取消后需新建任务。扫描过程中修改过的题建议再检查一次。

当前检查结构与答案引用、空题干、重复选项、原始填空占位符、概念逆向提示泄词、示例来源地址、已知冗余说明、明确答案结论疑似冲突、精确重复及客观同题不同答案候选。代码空格、运算符、大小写与否定词保留；填空代码示例不会当作模板清理。参考来源和独立解析均允许为空，不设置空字段告警；答案可已包含解释，内容是否充分需按具体题意核查。问题严重度分为结构错误、需重点核查和编辑提示；规则没有联网核验全部链接，也没有对每题事实作专家或AI鉴定，没有命中不代表内容已被证明正确。

精确候选只比较已扫描且未变化的签名，每题最多20条、每类问题展示最多5条。初次只扫描一个领域不等于跨全库比对完成，要建立全库覆盖请运行一次完整扫描。相似或重复候选不会自动合并或删除。

### 原地站内比对和AI复核

在编辑页展开具体质量问题的证据后，可使用“站内查找相似与冲突”查看有限候选，不必离开编辑页。候选的题面、选项、参考答案和组合材料可用于比较；相似不直接等于重复、错误或支持反馈。

可在本问题运行AI复核，也可选择最多20个问题批量复核。用户反馈直接使用本条反馈上下文；扫描问题会为原问题准备系统复核上下文，不再创建另一条用户反馈待办。AI结果、站内比较、修改建议和失败原因显示在同一问题证据中，详细诊断仍可打开AI处理记录。模型给出成立、不成立或暂不确定的建议，最终处理状态由用户确认，不自动改标准答案、发布状态或学习记录。

AI复核不声称检索了互联网；缺图、材料截断或依据不足时保留不确定。原题、候选或处理状态在分析期间变化时拒绝陈旧结果。失败项可重试。普通查询和确定性扫描不会自动调用模型。

### 升级、备份和恢复

可信JSON备份／迁移和完整SQLite恢复保留用户反馈、扫描、问题证据、AI复核记录及人工处理说明；普通分享不默认包含这些本地管理记录。升级和可信导入会为旧反馈幂等补齐质量关联，保留原反馈数量和已有结论。

参考来源改为可选后，旧版“缺少参考来源”自动提示会被清理；历史扫描保留当次原始发现计数，不会因此给题目重新产生缺来源问题。旧扫描的历史发现数与当前待处理问题数不必相等。独立解析同样可选：未处理且无关联证据的旧空解析提示会清理；已有人工结论或AI证据的记录仅供历史回看，不计入质量队列。

紧凑重复签名属于可重建派生索引，不进入JSON迁移，SQLite完整恢复后也会清空。恢复或迁移后若旧扫描游标前签名缺失，系统拒绝直接续跑并提示新建扫描；请新建全库扫描完成重建。普通查看列表不会触发迁移、扫描或后台模型请求。

### 下载、导入与审核

1. 获取可选的 `noetic-atlas-1.0.0-content.zip` 并解压。它包含各领域的 `part-001.json` 等分享分包、英语/日语词表Markdown、来源清单与许可文件。
2. 打开“分享与导入”，选择需要的领域分包，检查新增、复用和冲突预览后确认。每份最多500题，自带领域、祖先分类、标签、来源及所需图片，不用事先手动创建分类。不同分包可以分次导入。
3. 到待审核页，按领域、分类和标签筛选，核对释义、答案和插图后单题或批量确认。未审核题不会进入正式练习与随机组题；导入不会自行把新题改为已发布。
4. 英语和日语各附100份无分词汇表，每份100词。导入后先归档，审核对应词条后，从题集页恢复，检查或调整后保存，即可用于默写和复习。可导出空白卷、附答案卷或完成卷，格式为Markdown或PDF。

词汇原卡按简答题保存，答案和解析展示释义、例句及可用关联词。创建或编辑题集时，将“题集类型”设为“词汇题集”，例如创建“高频英语词汇100题”；成员须全部是带完整词汇信息和安全独立提示的词卡，普通语法题不能混入。通用题集继续使用原有练习方式。

词汇题集点击“开始练习”或选择考试模式后，可以选择本次方向：“顺向：看单词想释义”保留原简答题；“逆向：看释义想单词”将所选多张词卡转换为一份临时填空卷，不修改原卡类型。反向作答在交卷前不显示词头、读音、原例句、关联词、笔记与答案。填词按原词头及收录的日语常用假名匹配，忽略大小写和首尾空白；其他同义词不自动判为目标词。两种方向的历史和累计作答统计都归原题，FSRS记忆卡及到期安排按顺向、逆向分别保存。

草稿和历史记录标明当次练习方向，继续草稿沿用原方向；更换方向应重新开始一份练习。题量采样、逐题分值、练习计时和考试倒计时继续适用。单题查看页保留普通自测，方向选择统一放在题集开始流程。

本机现有200份自动英日词汇表已设为词汇题集，原归档状态保留；归档中的词表先恢复，再开始练习。手建题集可以在“题集管理 → 调整题目与分值”中设置题集类型。

现有英语、日语各10,000张词卡已补结构化读音。英语显示可查到的英式／美式IPA；只有一方来源时不凭空补另一方，单位、罗马数字或拼写变体的读法明确标为展开或变体。日语保留假名多读音，并显示由假名按赫本式规则转换的罗马音；罗马音不表示音高或重音。读音来源默认折叠，附答案MD/PDF可带读音，反向空白卷不会带出答案或读音。旧题集快照缺读音时，只读查看可补用身份一致的当前词卡读音，原快照正文与作答历史保持原样。

例句不一定覆盖一个词的全部义项，关联词也不等于可在任意语境中互换。反向释义存在近义词歧义时，以指定原卡词形为核对目标，可修订提示后再练习。

读题时，固定的词卡操作说明、“学习与审核说明”、完整数据许可和词典内部索引集中到默认折叠的“学习说明与资料许可”。题目、词卡、组题预览和答题页使用相同规则，整卷相同许可全文只显示一份。WordNet框架号、义项ID和例句出处可在详情中追溯，不再挤入词义及搭配正文；搭配里的占位语标注为某人（sb.）、某物（sth.）、动词（v.）、形容词（adj.）、名词（n.）、介词短语（prep. phrase）及不定式（inf.）。同一列表中去掉编号后相同的框架只显示一次，原始义项归属仍保留在详情；词形变化标题也去掉内部元数据标注。

Markdown和PDF导出将这些说明集中到卷末附录，并标明适用题号、去重相同条款。独立分享JSON和数据库保留原始出处与完整授权，接收方无需依赖发送者的网站才能查到来源。整理针对明确的模板，作答条件、真实例句、概念辨析、历史法规时效及化学药理安全提示继续显示；普通学习笔记与讨论许可证的知识题不按关键词隐藏。题目下方“资料来源与常见度依据”也可展开查看，站内原词卡与外部来源均可点击。

单份分享JSON和完整JSON导入仍受80MiB限制。大量题目连同词表快照、图片可能超过该限制，应使用提供的分包；完整跨设备迁移优先使用SQLite备份。项目 `data/content-packs/` 中的大JSON是内部构建数据，不直接作为普通新增模板上传。

### 源码环境下管理内容

完成源码依赖安装后，在项目根目录运行：

```sh
npm run content:validate
npm run content:package
npm run content:import -- --packs english,japanese
```

验证与打包可用相同的 `--packs` 参数选择[内容清单](./题库内容与来源.md#规模与发布状态)中的包名，逗号分隔；不传时处理全部内容包。例如 `npm run content:import -- --packs terms-chemistry,terms-medicine,terms-medicine-clinical` 仅导入相应专项；各领域基础术语20张另在`terms-domains`中。选择`driving`不会隐式导入两个历史资料包。打包输出位于`artifacts/content/`与`artifacts/releases/`，附清单和SHA256。

`content:import` 默认导入当前源码工作库 `data/noetic-atlas.sqlite`；先启动一次应用完成初始化。可显式传 `--database <已有SQLite路径>` 指向其他工作库。工具先做结构及引用校验，并在 `data/backups/` 创建本地恢复备份，再导入待审核题、集合和已归档词表。备份用于自己恢复，不作为内容分享文件。同ID不同内容时停止并提示使用分享预览解决冲突，不覆盖已有编辑或审核状态。

重新生成题库的来源下载、缓存及命令见[内容复现方法](./题库内容与来源.md#内容复现方法)。重建文件不会自动导入工作库，也不会自动通过审核。

## 资料库与书籍

### 分类方法

资料复用同一套领域、多级分类和标签，不另建孤立的“书籍领域”。资料类型和文件格式分开：

- 领域表示学科，可多选；细分类表示章节方向或专题。
- 类型可选择书籍、学习笔记、学习路线、参考资料、项目资料，也可填写自定义类型。
- 格式为Markdown或PDF；“PDF”不再充当内容类型。
- 标签表示交叉主题，通用/个人属性表示资料用途。
- 书籍可填写作者、出版社、出版年份/版本和简介，便于检索与管理。

列表支持组合筛选领域、分类、资料类型、格式、标签和内容属性，并搜索标题、作者等内容。旧资料未显式指定领域时，从原分类只读推断，不批量改写原始数据。之后编辑可明确调整领域。

### 上传和阅读

点击资料库顶部“新建 / 上传资料”，选择UTF-8 `.md`、`.markdown` 或 `.pdf`，检查标题和归类后点击头部保存。读取文件成功不代表记录已保存。

MD上传后成为可编辑正文，后续编辑和下载以当前正文为准，不另存一个过期的原始附件。PDF保留原始字节；桌面提供本地预览和下载，Android通过保存/分享交给设备已有的PDF阅读器。PDF不会自动转成Markdown，也不自动OCR。

Markdown正文提供编辑／预览标签及格式工具栏：标题、粗体、斜体、删除线、引用、行内代码、代码块、无序／有序／任务列表、链接、表格和分隔线。选中文字后可直接应用格式，也可在光标位置插入模板；图片插入当前光标或选区。支持撤销／重做及Ctrl/⌘+B、I、K快捷键，切换预览不会清空正文。预览使用与资料阅读相同的渲染规则，支持任务列表和表格。工具操作会进入自动草稿，完成后仍需点击“保存资料”才成为正式资料。

### 资料编辑草稿

资料新增与编辑会在停止输入后自动保存独立草稿，等待时间沿用系统的“自动保存等待”，默认1000毫秒；也可点击页头“保存草稿”。草稿包括正文、标题、作者、归类、标签及图片／PDF附件，标题或资料类型尚未填完也能保存。没有改动的空白表单不会创建草稿。页面显示待保存、保存中、已保存或失败状态；草稿保存不等于正式保存，草稿不会出现在资料列表或内容分享中。

再次进入新增页面或某份资料编辑页时，如果有草稿，会先显示“继续资料草稿”，按最近保存时间选择继续、删除某稿，或重新开始。继续会更新同一份草稿。新增资料入口和每份已有资料的编辑入口分别默认保留最近3份，可在系统配置调整；降低上限会先确认清理数量。

点击“保存资料”会先保存当前最新内容，再在同一事务内创建／更新正式资料并清理当前草稿，其他草稿继续保留。已有资料的草稿不会提前改动正式正文。原资料在其他页面被更新、归档或删除时，会保留当前输入和草稿并提示冲突，可另存为新资料；同一草稿被其他页面修改或删除时，也可将当前输入另存为新草稿，避免相互覆盖。

存在尚未正式保存的更改时，内部跳转会先询问并保存草稿，保存失败会留在当前页。刷新或关闭使用浏览器原生提示，切换到后台时尽力保存。系统强制关闭、浏览器退出或存储故障可能中断最后一次请求，应以“资料草稿已保存”状态为准。完整JSON／SQLite备份包含资料草稿；仅导出配置或分享内容不会带出私人草稿。被草稿引用的图片／PDF受资源引用保护。

上传MD不会自动读取旁边的图片文件夹。相对图片路径需要重新上传插图，或预先转换为受支持的内嵌图片。支持PNG、JPEG、GIF、WebP，不接受SVG；远程图片不会自动加载。图片单边最多16384像素，总像素不超过4000万。

默认每份资料20MiB、每张图片5MiB，系统配置可调整。上传和新保存正文会检查实际大小及格式。归档资料不主动删除文件；仍被题目、资料、笔记、题集、历史快照或独立错题快照引用的文件不能在资源管理中删除。

## 题集与计分

题集列表顶部“创建题集”直接进入手动组题，旁边的下拉提供随机选题方式，AI推荐和随机抽一题保留独立入口。搜索、领域专项、归档筛选、页码和每页数量保存在当前网址，同一浏览器标签页返回列表时继续原位置；使用“清空筛选”可恢复全部题集。未交卷练习返回草稿列表，已交卷返回历史答题。直接进入随机练习的草稿或历史记录时，筛选区默认收起，先展示目标记录。

### 组织和组题

题集统一替代原练习卷和独立题库集合，可用于浏览学习、普通练习、考试与导出。题集分为指定领域专项和其他，列表可分组、筛选。题集所属领域用于管理，随机抽题的领域/分类/标签条件独立设置。

题集详情顶部按三组操作组织：“开始练习”主按钮直接进入普通练习或选择草稿，旁边箭头可选普通练习、考试模式；“导出与分享”打开导出或分享窗口；“题集管理”包含调整题目与分值、归档／恢复和永久删除。归档与删除仍须确认，已归档题集需先恢复才能新建练习。下拉菜单可用方向键选择、Escape收起，点击页面其他区域也会收起。

点击题集中的题目，进入独立的题集阅读页面，使用与题库详情类似的正文和学习侧栏。“上一题／下一题”按整份当前题集的保存顺序切换，包括组合题展开的小题，不受题库列表或题集内容搜索结果影响；首尾不能越界。点击“返回题集”回到原题集，保留进入时的内容搜索、页码和每页数量。阅读地址可刷新或直接打开，页面明确显示所属题集及当前题目位置。

显示的是保存到题集的内容快照，源题后续修改或删除不改变当前阅读内容。收藏、笔记和复习进度只写入仍存在的原题；原题不可用时仍可读快照，不会自动创建新学习记录。笔记未保存时，切换题目或离开会先确认；刷新或关闭使用浏览器原生提醒。题集快照内不调用原题AI解析，以免内容与版本混用；需要AI解析时，可在知识题库中针对当前原题使用。

大型题集保留全部内容。每次作答最多500个展开作答项，开始练习或考试前可设置本次选题数量，并选择“从题集中随机抽题”或“按题集顺序从头选题”；组合题整组保留，若小题展开后超限需减少数量。不会自动取前500题代替整份题集，本次作答按选中范围独立保存题目和分值快照。

手动组题可搜索并跨页选题、调整顺序和分值。已选列表默认每页20题，可调整每页数量；翻页、调整顺序不影响其他已选题。编辑或恢复组题草稿时批量核对当前题目状态，核对失败可重试，表单和选题仍保留。随机组题支持领域、分类及子类、多标签AND/OR、题型、难度、常见度和内容属性；题量不足会明确提示，不自动放宽条件或补重复题。

点击候选题或已选题的展开箭头可在原处查看题干与解析，不会跳转离开编辑器。组题表单自动保存为独立的组题草稿，包含筛选、选题、顺序和分值。再次进入时可选择某份草稿继续或新建；继续编辑覆盖同一份草稿。新建入口和各卷编辑入口分别保留最近3份，可在系统配置修改。保存失败或版本冲突时会提示，离开前应核对保存状态。

组题仅使用已发布题目。归档题集保留历史且停止新建作答，全部成员审核发布后，可从顶部“题集管理 → 恢复题集”恢复。旧集合迁入且尚未编辑的无分题集，首次恢复时重新读取已审核题目并产生新版本；其他恢复保留已保存的题目和分值。永久删除源题集保留已有作答草稿和历史快照；复盘页会说明原题集已删除，不展示失效的详情链接。

### 概念题集与双向练习

概念卡不局限于英语或日语。编辑简答题时勾选“作为可双向练习的概念卡”，填写概念主词、独立短定义和可接受别称。例如“沉没成本”的独立定义可以是“已经发生且无法通过未来选择收回的支出”。定义中不能直接写出主词或已收录别称，例子、详细解释和来源继续放在答案解析中。

在题集编辑页将“题集类型”设为“概念题集”，仅加入已有概念字段的已发布简答题。开始练习或考试前选择方向：顺向“看概念想含义”用于主动回忆并对照解析；逆向“看描述想概念”仅显示独立定义，填写主词或已收录别称后自动核对。交卷前隐藏概念名、例子与详细解析，避免直接暴露答案。草稿保存方向，续答保持原方向。

概念卡沿用同一原题ID、笔记和累计学习记录，FSRS为两个方向分别记录回忆与复习计划。旧普通题已有复习卡时，补充概念属性后沿用原卡作为顺向，保留记忆及事件，不产生重复的顺向到期任务；逆向仍单独安排。分享JSON、数据库迁移和题集快照会保留概念字段，不要求音标，也不把专业术语登记成语言单词卡。含多个概念或无法用短定义唯一指向名称的场景题继续按普通简答题学习。

知识总览的领域卡同时显示分类数、已发布题目数和待审题目数；同一题关联本领域多个分类时只计一次，跨领域题在各所属领域分别出现，因此领域数值之和可能大于全库独立题号数。草稿和归档题不进入这两项计数。

### 计分规则

初始默认无分练习，也可启用计分。手动卷逐题填写分值，可指定总分；合计一致后保存。随机计分初始默认100分，客观目标60%、主观目标40%，按题型分值寻找精确总分且最接近目标比例的合法组合。实际比例会显示，凑不出时需要调整规则。

初始每题分值：判断1、单选2、多选4、填空2、简答3、论述10、组合整体6分。组合父题按小题权重分配，使用整数最小单位维护精确合计。每题0.01—1000分、总分最多10000分，最多两位小数。

交卷先算客观分。主观题未阅完时标为待阅，最终总分不提前产生；已阅0分与未阅不同。人工可评分、修正或撤销；AI可给建议，确认应用后进入同一判分流程。掌握程度0—3与题集分数分开。

保存的题集和开始作答时都冻结题目及分值。修改题目、系统默认值或新版本卷面，不改变已有草稿和历史成绩。

无分题集也保留创建时的题型默认值，实际逐题分值和总分始终为0；更新系统默认分值后仍按原配置读取和迁移，不要求旧题集匹配新的默认值。

## 题集草稿与学习记录

### 练习计时与考试模式

普通练习默认顺计时，只累计实际处于答题页前台的时段。退出答题、切换页面、刷新或切到后台时暂停，重新进入或返回前台后从已有时长继续；退出后浏览草稿不会启动计时。保存草稿不清零、不新建计时，提交后冻结并保存本次作答用时。答题卡与页头均可交卷。

普通练习按毫秒累计、按整秒显示，多个短时段不会每次丢掉不足一秒的部分。前台每30秒保存计时检查点，离页、手动保存和交卷时也会保存当前时段；旧草稿从已保存的用时继续，不能还原的旧离页时间不补算。浏览器或手机被强制结束且未能保存最后时段时，可能丢失最后一个检查点后的时间，但不会把停用期间计入作答。

整卷练习、考试和随机／单题作答页不展示旧笔记、历史作答统计或掌握程度，也不提供笔记编辑器。需要整理笔记时，在知识题库查阅原题，或在题集的看题页面编辑；交卷后可从参考解析中的按钮打开原题。作答页的掌握自评与AI评价仅在交卷后出现。

考试模式在开始前可设置时长，默认120分钟，范围1—1440分钟，默认值可在系统配置修改。开始后截止时间由数据库保存，刷新或重开不会暂停或重新计时。同一数据库同时只允许一份未交考试。考试期间应用内部导航、搜索和返回其他功能会被拦截，提前交卷或时间结束交卷后解除。

到时以截止前成功保存的答案自动交卷，超时到达的答案不会覆盖。浏览器关闭或系统强制停止时，应用无法阻止操作或在停机期间执行代码，重新进入后立即核对并封存过期考试，记录的交卷时间仍为原截止时间。请及时完成保存。

作答期间答题卡以灰色区分未作答、蓝色区分已作答；交卷后区分未作答、正确、部分正确、错误和未判定。主观题待阅属于未判定，人工或AI判定应用后同步更新；部分得分归为部分正确，同时显示具体分值。每种状态均配文字说明。

### 草稿与历史

每份卷初始默认保存最近3份草稿，随机单题独立保留3份。进入时可选继续某次作答或重新答题。继续保存覆盖原ID，重新答题才新建；超限清理最旧未提交草稿。上限可在系统配置修改。

题集详情统一提供内容、草稿、历史、错题和复习入口，记录只展示当前题集范围。随机答题和从知识题库开始的单题自测，统一在“随机抽一题”页面查看草稿、历史、错题及复习，不再设置独立的全局学习记录页面。已提交历史初始默认不限量，0表示不限；可以为每份题集和随机自测分别设置上限。调低上限会先显示清理数量再确认；历史按提交时间保留，复盘或重新评分不会延长寿命。

看题页面还提供该题的答题记录，汇总来自不同题集及随机自测的实际填答次数、正确、部分正确、错误和未判定次数；组合题按当前小题分别统计。只保存草稿、只看答案或交卷时漏答均不增加填答次数；主观题只有空白也视为漏答。同一次作答重新评分会更新结果，不重复计次。

单题详情默认独立保留最近10次实际填答，配置项 `maxQuestionHistory` 可调整；0关闭这份独立详情。它与整卷历史上限分别生效：单题超限不会删除整卷，仍可从整卷复盘；整卷先清理时，仍在单题保留范围内的题目快照与当次回答会留下。两边详情均被清理后，累计统计继续保留。统计从升级时仍能核实的作答建立；旧版本已清理且无法确认是否填答的记录标明统计范围，不猜测补计。

普通题集卡片将错题、收藏、待复习、草稿、历史答题五个入口放在同一行，显示对应数量，点击即可进入本题集的相应页签。统计按当前显示的一页题集批量读取，加载或读取失败时显示“—”，可重试。

题集列表顶部固定显示“全部错题”“全部收藏”“待复习”三个系统题集，不受普通题集的搜索、领域筛选或分页影响。它们随学习记录自动更新，不创建重复题目或普通题集，也不能归档或删除。列表支持分页与每页数量；点击题目进入独立阅读页面，使用上一题／下一题跨页连续阅读，返回恢复原列表的页码及每页数量。题集内和随机／单题自测来源的错题、收藏、复习列表，以及FSRS实时复习队列也使用同一页面方式，不再使用看题弹窗。

特殊题集阅读地址使用 `#/learning-reader`，保留所属范围、题目定位与列表上下文；从实时队列进入还会保留任务类型、领域、分类和方向筛选。错题按对应来源保留当时快照，收藏与待复习按当前可用原题读取。仍存在的原题或小题可保存学习笔记与复习状态；笔记未保存时，翻题或离开会先确认。题目因收藏、错题或复习状态变化而不再属于当前范围时，刷新页面会明确提示并提供返回入口。

全部错题按原题和小题去重，同题在不同来源仍有错误时合并展示，保留每个来源最近一次已判错误的题集名称、版本和作答时间，包括随机自测和已删除的题集。在某题集中答对只解除该题集的错误，不会清除其他题集的错误。阅读默认采用最近错误作答保存的快照，整卷历史仍存在时可进入对应复盘；整卷历史清理后，来源会注明历史已清理，错题内容与来源仍可查看。

全部收藏、待复习按存活原题的当前内容整理，包含从未加入题集但已在知识题库收藏或安排复习的题目。可展开查看完整关联题集和作答；无关联时标注知识题库来源。关联来源用于说明题目的收录和练习关系，不代表能追溯实际在哪个页面点击了收藏。

题集与练习可按领域、分类和标签“随机抽一题”，再次随机排除当前题。可作答提交，或主动点击“先看参考解析”；未主动展开前不显示解析与旧学习内容。仅查看解析不自动提交，不把空白答案计为错题。收藏和笔记在查阅原题或题集看题页面整理，交卷后可进行本次掌握自评。

题集错题按本题集中已提交作答的每个小题最新已判结果计算，答对后移出；未判主观题不会被视作错题，也不覆盖上次已判结果，未答客观题需要巩固。人工或AI应用主观评分后同步更新；撤销评分时回退到该来源此前仍有判定的结果。较早作答重新评分不会越过较新的提交。错题查看使用当次作答快照，不以当前原题替换；不同题集之间的答题结果独立。

题集与随机单题共用存活原题或对应小题的学习状态；组合小题有各自掌握程度、笔记和复习日期，收藏属于整组。题集范围只展示相关题目。原题删除后可查看历史与错题快照，但不能新写原题学习状态。永久删除题集后，“题集与练习”保留已删除题集的历史入口，可继续保存的草稿、复盘或独立错题；不会重新创建原题集。复盘返回所属题集历史，随机／单题返回随机页历史。

笔记、收藏、掌握、错题和复习记录与题目内容分开。默认由FSRS根据回忆反馈安排下次复习；掌握程度0—3仍可单独记录。切换为固定间隔时才使用初始1、2、7、21天规则。整卷与单题详情各按自身保留上限清理，错题状态、累计统计、错题快照、来源、掌握程度、笔记及FSRS卡片和反馈继续保留。此规则从升级时仍存留的历史开始建立，升级前已被删除的历史无法自动补回。需要清空进度时使用系统配置中的独立重置入口。

查阅单题时，右侧“学习情况”集中显示实际作答、正确、部分正确、错误、未判次数，以及掌握程度和复习日期。主内容的“详细历史作答”只展开当时题目、完整回答、判定和来源。题集看题页面与组合小题采用同样分区；手机窄屏时按阅读顺序上下排列。

## 自适应复习与实时队列

默认使用本地FSRS-6调度，无需AI或联网。查阅原题或题集快照时，“自适应复习”显示下次日期、有效回忆次数、当前学习状态及四档反馈对应的下次安排。先独立回忆，再核对答案并选择本次反馈；掌握程度0—3、题目分数和回忆反馈各自保存。

| 回忆反馈 | 选择依据 |
| --- | --- |
| 重学 Again | 想不起来、答错或有关键遗漏，需要重新学习。 |
| 困难 Hard | 已独立完整答对，但回忆费力。 |
| 良好 Good | 能正常独立回答。 |
| 轻松 Easy | 完整回答且几乎不费力。 |

“困难”不代表部分正确。默认客观题交卷后，正确自动记良好，错误记重学；主观题须已实际填写且完成人工或AI判定，完全正确记良好、部分正确或错误记重学。提前查看过参考解析后再交卷，即使答对也记重学；错误、关键遗漏或辅助作答不能改成困难、良好或轻松。漏答、空白主观题、未判主观题、草稿和单纯查看解析不产生回忆事件。可在系统配置关闭客观题自动记录，再于交卷后确认评级。

交卷后的各题“自适应复习”可更正本次反馈或恢复自动评级。修正人工分、应用AI评分或撤销主观判定会更新原事件并重算后续记忆状态，不把修改当作新一次复习；统计仍归原交卷时刻。重新完成一次实际作答才增加一条反馈。独立看题中的手工评级则记录本次新回忆。

普通题独立排期，组合题按稳定小题身份分别排期，复习甲小题不影响乙小题。词汇顺向“看词想释义”和逆向“看释义想词”各有卡片、次数和下次日期；暂停某方向不阻止另一方向到期。旧整组日期仅由没有独立卡片或显式小题计划的小题继承，显式空日期、未来计划和暂停卡片不会从父题重新冒出任务。原题删除、未发布或小题失效后，历史仍保留，可复习队列不再提供失效任务。

进入“题集与练习 → 待复习”，实时复习队列可筛选全部到期、逾期、短期重学、今日到期，以及领域、分类和词汇方向。它按当前时刻读取，短期学习／重学到时即进入队列，不需要等待下一次每日推题；未到期任务不提前显示。分钟重学优先，其后按日期排列。逾期按系统配置的时区日期判定，因此短期重学也可能同时逾期。

看题中的“暂停或调整复习日期”可暂停／恢复当前卡片、手工改期，或恢复算法排期；这些操作不增加回忆次数。旧版复习日期在首次有效FSRS回忆前保留，不补造过去的遗忘记录。更改FSRS参数只用于之后的有效反馈；切回固定间隔可继续旧规则，已有FSRS历史保留，之后切回FSRS继续使用保留卡片。

## 统一搜索

在右上角“全站搜索”输入关键词并按回车，或点击搜索按钮，进入统一结果页。非编辑状态下可用Ctrl／Cmd＋K聚焦该输入框，Esc取消聚焦；不会接管正在编辑的输入框，考试期间不可搜索。

结果按全部、题目、题集、资料、笔记、领域、分类和标签筛选，各类型显示命中数量。支持相关度、更新时间排序，以及分页和调整每页数量。关键词最多100个字符、8个词，用空格分隔时取交集；英文忽略大小写，全角／半角按NFKC规范化，百分号、下划线和引号按字面匹配。相关度优先编号或标题精确匹配，再考虑前缀、标题和正文。

| 内容 | 搜索范围与打开位置 |
| --- | --- |
| 题目 | 编号、标题、题干、选项及组合小题内容；参考答案、解析和填空标准答案可用于匹配，结果不会直接显示答案正文。打开原题查阅。 |
| 题集 | 名称和简介，打开该题集。 |
| 资料 | 名称、作者、出版社、简介等元数据；Markdown可搜索正文，PDF暂不提取附件全文。打开资料。 |
| 笔记 | 已保存的整题、小题学习笔记，打开原题；小题笔记定位到对应小题。 |
| 领域／分类／标签 | 名称和简介，打开对应条件的题库列表。 |

默认排除归档内容和未发布题目；勾选“包含未发布题目”可检索待审核、草稿题及其笔记，结果标出状态。这不会通过审核，也不会让未发布题目用于组题。未保存编辑稿、资料／组题草稿、历史私人回答、AI配置和附件字节不在搜索范围内。

点击结果后的“返回搜索结果”，可以回到原关键词、类型、排序及页码；浏览器返回同样可恢复查询。结果摘要和高亮以纯文本显示，图片和格式代码不会作为页面脚本执行。搜索索引保存在本地SQLite，随编辑、删除和迁移自动更新或重建；首次升级会建立索引，后续查询只读取轻量索引和当前页摘要，不加载全题库正文。搜索无需AI或联网。

## 学习统计、分析与周报

从侧栏“学习统计”或知识总览下方的“本周学习统计”卡片进入统一统计页面，默认查看本周周报。总览卡片展示本周实际作答、严格正确率、已知作答计时和活跃天数，与统计页使用同一接口和口径；卡片每分钟及窗口重新获得焦点时刷新。原顶部两个重复入口已合并。

顶部选择“日／周／月”，通过日期、月份控件或上一期／下一期翻页，点击今天、本周或本月回到当前期间，不能进入未来期间。也可查看近一年（含今天的365天）或自定义起止日期，一次最多366天；其他范围提供“查看本周周报”快捷按钮。日期范围保存在当前页面网址中，刷新保留。日期按系统配置中的时区归属，初始为Asia/Shanghai；改变统计时区可能改变跨日作答所属日期。需要最新判分或复习情况时，点击“刷新统计”。考试进行中暂不能访问统计。

| 指标 | 口径 |
| --- | --- |
| 实际作答次数 | 仅计算已填写并提交的回答；重做增加次数，草稿和漏答不增加。组合题按小题计算。 |
| 去重作答项／原题 | 同一原题及小题跨题集重复作答只计一个作答项；整组材料对应一个原题。 |
| 提交次数 | 包含空白交卷；“有实际回答的提交”单独计数，避免把提交量当作学习量。 |
| 严格正确率 | 完全正确÷（完全正确＋部分正确＋错误）；部分正确不算完全正确，未判、漏答及未知项不进入分母。没有已判作答时显示“—”。 |
| 作答计时 | 只汇总有实际回答且有可靠计时记录的提交，按交卷日期归属。可能包含停留时间，不等同专注学习时长；缺少记录会提示，不推测补齐。 |
| 活跃天数／复习记录 | 当天有实际答题或复习记录即为活跃；复习动作单独计数，不与作答次数相加。 |

每日趋势可展开明细并分页，较长范围按7天合并图表，明细仍保留每天数据。判定分布分别展示正确、部分正确、错误及未判。领域和题型表支持分页、调整每页数量；同一题可以归属于多个领域，领域分项不能直接相加。旧记录或已删除归类无法核实时，归入未知／未分类并提示缺失情况。建议根据待判数量、已有样本表现和复习节奏生成，至少有3次已判作答才据领域正确率提示加强方向；这些是规则建议，不是能力评级。

“学习周报”按周一至周日自动汇总，选择任意日期可查看所在周，支持上一周、下一周及回到本周。已结束周对比完整上周；本周进行中时按已过秒数对比上周同等长度的时段，避免周初与完整上周直接比较。当前周还未到的日期标为“未到日期”。变化显示绝对次数、时长或正确率的百分点，没有已判基数时不制造增幅。

点击“导出周报Markdown”可保存当前所选周的概览、对比、每日表、领域／题型表现、建议和统计口径；Android使用系统文件分享。周报在本机实时计算，无需AI或网络，也不另建定时任务。后续判分会更新历史周报，已导出的文件保留导出当时的结果。

“复习如何转化为记忆”另列FSRS反馈次数、去重复习卡、四档分布和回忆成功率。回忆成功率＝（困难＋良好＋轻松）÷全部反馈，重学计失败；它与上方严格答题正确率分别统计，无反馈样本时显示“—”。同一原题的小题或词汇方向按不同卡计去重，重复复习分别计次。首次、提前、已到期和逾期表现以事件前FSRS记忆计划划分；首次尚无复习周期，历史手工改期或旧固定计划不能据此推断准时率。

包含今天且有可靠队列快照时，显示当前积压、逾期、已到期短期重学和暂停数量，并提供“本时段到期处理比例”：本时段完成的到期／逾期复习周期÷（这些周期＋当前仍到期的可复习任务，含旧计划）。一张卡可经历多个周期，暂停任务不进入分母；这是当前处理情况，不能当作历史计划完成率。已结束周、上周同期等历史截止点没有可靠队列快照，因此队列和比例显示“—”并说明原因。统计与周报均按实际截止时刻取反馈，不包含之后的事件；导出的Markdown包含相同FSRS指标、对比和口径。

统计以独立学习摘要为主要依据，清理整卷和最近单题详情后仍可保留累计活动。新提交保存轻量题型、分类及计时信息；旧记录仅从仍保留的作答元数据核实，缺失信息如实标注，不改写旧记录或读取全部题库正文。主动重置学习进度会清除对应摘要和复习记录，重置前保留的卷面不会自动重新计入统计。完整SQLite／JSON备份迁移保留学习摘要；题库分享包和配置文件不包含个人统计记录。

## 导出与分享

### 阅读文件

题集详情或已提交复盘页可导出Markdown和中文PDF：

| 模式 | 内容 |
| --- | --- |
| 空白卷 | 题干、选项、分值、答题区，不含答案与解析 |
| 附答案卷 | 题目、参考答案、解析与来源 |
| 完成卷 | 本次实际作答、参考答案、客观结果与主观阅卷状态 |

历史导出使用当时快照。未交卷的练习不能提前导出参考答案或完成卷。空白卷不泄漏填空答案别名或答案图片。

MD下载内嵌本地图片，单文件便于移动。PDF在本机嵌入中文字体、自动分页；PNG/JPEG直接嵌入，GIF/WebP取静态帧。远程或失败的图片给出明确占位，不后台下载。超宽表格转换为记录形式；字体未覆盖的字符以码点提示。完整中文字体使单份PDF有约6MiB的固定开销，大卷可先导出MD或拆卷。

### 可导入的分享包

单题、筛选出的题目和题集顶部提供分享入口。选择JSON时生成独立 `learning-share` 包，包含选中题目、所需领域、祖先分类、标签、相关本地图片，以及适用的题集快照与分值。对方不需要预先创建同名领域、分类和标签。

接收方打开“分享与导入”，上传JSON或粘贴内容，先看新增、复用和冲突另存的预览，再确认导入。相同内容可复用；同ID不同内容使用新ID，并一起改写分类、标签、图片及卷面引用，不覆盖本地编辑。预览后本地数据变化会要求重新预览。任一依赖或图片无效，整批不落库。

分享导入的新题全部待审核。含新题的分享题集先归档，审核题目后可恢复编辑保存，避免绕过审核直接练习。原发布状态只在可信完整备份迁移入口保留。

分享包不包含私人笔记、学习记录、草稿、系统配置、AI密钥或本机来源路径。题目正文若含个人经历，仍需分享前自行检查。单份JSON最多80MiB，附件多时分批分享。

### QQ、微信等平台

可导出单题或题集的分享PDF，包含答案与解析，适合阅读。需要空白卷时使用题集的常规导出功能。电脑下载后自行发送；Android由系统分享面板选择QQ、微信、文件管理器等目标。PDF用于阅读，JSON用于导入另一套系统；系统不直接代发聊天消息。

## AI辅助

### 配置模型服务

进入“系统配置 → AI辅助”，启用后填写API端点、模型名，以及服务需要的API Key或Token。接口采用兼容Chat Completions的HTTP协议；可接入兼容云服务或自行部署的vLLM/Ollama服务。保存后使用连接测试，实际模型与可用能力由你配置的服务决定。

密钥保存后只显示“已配置”，留空可保留原值，也可主动清除。可调整超时、输出上限及图片能力。只有支持图像的模型并开启发送图片时，才发送题目已有的本地插图；未发送图片会给出警告，含缺失图像的审核不会自动通过。

最大输出Token的初始默认值为16384，仅影响新配置；升级不会覆盖已保存的数值。这是单次输出上限，并非每次固定消耗，仍须符合所用模型的限制。题目完整字段修改和批量处理容易产生较长结果，可按需增大或分批处理。模型因达到输出上限而截断时，错误会注明本次上限和调整位置，不应用不完整结果，也不自动重试。

各功能中的“配置AI辅助”提示和入口只在AI尚不可用时显示。配置完成后可直接使用AI功能，需要调整时仍从系统配置进入。

AI默认关闭。开启后，点击具体AI操作才把本次请求的题目、参考答案、解析、作答或提取的资料发送到该端点；推荐组题只发送本次范围内检索出的候选摘要与必要分类目录，不发送参考答案、学习记录或图片。HTTP本地端点会明文传输内容和凭据；访问云服务宜使用HTTPS。Android通过原生HTTP访问配置服务，普通离线学习仍无需网络。

### 处理进度和取消

发起AI操作后，进度面板显示当前工作步骤与已用时。网页和Windows桌面端可在模型生成时实时看到解析、评价或推荐理由等文字预览；多批组题还显示已完成数量。预览尚未经过完整校验，只有显示处理完成并出现正式结果后才能应用、导入或保存题集。系统展示实际工作阶段与答案片段，不输出模型隐藏思考；若模型服务只返回完整响应，面板会说明这一状态。

处理期间可以点击“取消本次处理”。完成前取消或断线会停止后续处理，未完成结果不保存、不用于评分或自动发布题目；已有的上次完整结果仍保留，并标明它属于上次处理。Android当前网络通道需等待完整模型响应，只显示真实的连接、生成、校验和分批选题等阶段，不模拟逐字输出；取消后忽略迟到结果。手机只有在本地数据库成功保存后才确认处理完成。

### AI辅助编辑题目

打开已有题目的编辑页，使用“AI辅助编辑 → 分析当前题目”。可展开“补充编辑要求”指定侧重点。分析使用点击时的当前表单，包含尚未保存的题干、选项、答案、解析与分类标签，以及本题已有质量问题；不发送学习笔记或历史作答。只生成建议和处理记录，不直接改动题库或质量状态。

每条建议分别展示原因、核对提示、分析时内容和建议内容。点击“应用本条建议”只修改该条对应的表单字段；选择题的选项和判分答案可作为一条关联建议一起修改，组合题建议定位到既有小题。分类标签使用系统已有项，不自动创建新领域、分类或标签。题型、发布状态和小题身份不会由建议更换。

应用后可用“撤回本条修改”恢复该条修改前的字段，其他编辑保留。分析后手动修改了相关字段，或应用后又更改了相关字段时，系统会提示冲突，保留当前内容；请重新分析或手动核对。修改其他字段不妨碍应用互不冲突的建议。重新分析成功后仍保留此前已应用修改的撤回入口。

应用与撤回都属于当前编辑会话，最终点击“保存题目”才写入数据库，仍遵守原有版本、审核和质量提醒。已有应用建议时，也可使用“保存并继续编辑”留在本页，继续修改或撤回；已保存后再撤回也只是在表单中恢复内容，需要再次保存。离开编辑页后不保留本次撤回操作记录。AI修改建议不自动关闭质量问题，不改动历史卷面或学习状态。

进度、取消、失败诊断和AI配置复用其他AI功能；失败或取消不会应用未完成建议，上一次完整结果继续保留。完整分析结果及失败记录可在AI处理记录的“题目辅助编辑”类型中查看。

### AI主观评价和判卷

简答和论述题可输入回答，获得针对本次作答的评价、优点和改进建议。组合题请进入作答后选对应主观小题。已提交练习可选择单题或多题交给AI对照快照评价，并填写本次判题要求。结果给出正确、部分正确或错误；计分卷还给出限定满分内的建议分，无分练习可应用文字判定，不产生数字成绩。

作答结果页统一使用顶部“AI辅助评价”入口，题卡内不再重复放按钮。仅一道主观题时显示“AI评价本题”；多道主观题时在弹窗中勾选一道或多道，每批最多20题。普通题集、随机答题和单题自测沿用同一流程，未提交作答及纯客观题不显示评题入口。

判题请求提供明确的JSON结构、允许的题号与字段清单。模型额外附带的字段会被忽略，缺省或null的优点／改进列表按空列表显示，并在结果提示；这些兼容处理不改动判定和分值。题号缺失或越界、分值类型错误、满分不符、得分与判定矛盾等仍拒绝保存。失败提示显示具体校验路径和问题，完整诊断保留在AI处理记录中；失败不会修改原有成绩，不会自动重试或应用结果。

生成建议不会直接覆写成绩或判定。检查后可显式应用选中结果，或将评价追加到原题笔记。已有笔记保留，重复应用不重复追加；同一作答不会因再次应用而增加填答次数。单题评价的满分最多两位小数。模型生成期间或之后，作答、人工判定或题目版本发生变化时，系统会要求重新分析。

### AI推荐组题

AI工作台的“AI推荐组题”可以直接输入目标，例如“从计算机领域选50道Go并发与网络题，基础题过半，保留两道场景题”。领域、分类、标签、题型、难度和数量都可以写在提示词里，不必先选择筛选。题量自动从要求中读取，没写数量默认20题；也可勾选“手动指定题量”，填写1—500，手动数量优先。

“高级筛选”是可选的硬限制；已选领域、分类、标签等条件必须满足，提示词不能把范围扩大。系统只使用已发布题目，从大题库检索候选摘要并按需分批推荐，候选范围可以超过300题。每次AI推荐仍最多500个独立作答项：普通题占一个，组合题按展开后的小题数计算。数量不足、组合题超限或题目版本变化会明确提示，不能靠重复选题或放宽范围凑数。

完成后显示可用范围、检索命中、实际由模型比较的候选量和批次数，便于检查是否符合要求；这些数量不同，命中不表示所有题目正文都发给了模型。预览逐题展示选择理由，支持展开查看、移除、从本次候选中补题、调整顺序和逐题设置分值。检查后点击“确认创建题集”才生成正式题集；仅完成推荐不会自动创建。

### AI解释

题目页可把原题、答案、原解析交给模型进一步解释，分别展示补充说明、追问和常见误区。原解析保留，AI结果单独记录，可追加到笔记；不会把AI输出直接当成原题标准答案。

### AI辅助导入

进入“AI工作台 → 文件 / 文本辅助导入”，可读取PDF、TXT、MD、Markdown、JSON和CSV，单文件最多30MiB、PDF最多150页。先在本机提取文字，检查章节范围后选择处理方式：

- **整理已有题目**：提取资料中现成的题目、选项、答案及解析，保留原意；不会把纯知识正文当成现成习题。
- **教材知识出题**：从教材、讲义的正文提炼概念、原理和应用，生成可作答的练习及答案解析。可以填写出题要求、题型范围、难度和本批最多题量，例如“根据本章生成基础判断、选择、填空和简答题，用中文解析”。

每批最多50题，材料不足时可以少于所填上限。服务端会核对数量、指定题型、难度和生成题的重复题干；这些结构检查不代替内容核验。来源名称随题保存，可填写公开来源链接用于署名；系统不会访问该链接或代替上传文件。教材出题的来源链接由用户填写，模型不能自行补造来源。

模型给出结构化候选题及领域、分类、标签建议。可以修改候选JSON、选择需要导入的题，再确认。预览不写入题库，建议新分类也不会在模型回复时自动创建，应检查并选择创建或采用现有分类后再导入。处理记录保留结构化结果与来源信息，不保留上传文件及完整输入正文。

所有确认导入的新题进入待审核区。转换不能保证原答案正确，也不会为凑数虚构缺失内容。扫描PDF没有可提取文字时需先OCR；复杂排版、表格、公式及图片题应检查提取结果并补齐插图。大书籍宜按章节分批处理。

### 多文件与教材分批处理

在“AI工作台 → 文件 / 文本辅助导入 → 多文件 / 教材分批”选择文件或粘贴正文。支持最多20个文件、单文件30MiB；PDF本机读取最多2000页，可选择PDF文件页码范围。扫描页没有文字时会提示，本功能不自动OCR。原单次整理入口仍有150页限制，长书请使用分批入口。

本机按页段／文本拆成适合模型的小块，显示文件、页码、字符数和提取预览。确认创建任务后，提取正文保存在本机任务中供恢复，不保存原始上传PDF；任务列表与普通处理记录不返回整份正文。任务最多400万字符／12MB、600块。来源URL只用于署名，不会自动下载。

先选块执行“AI总结”，每块显示主题、摘要和知识点，再勾选某块或全部生成题目。每个请求最多处理5块，页面自动多轮继续；每块上限50题，任务总预算最多2000题。选块较多时按剩余预算下调每块题量，预算不足每块至少1题时先提示调整范围。AI总结的主题不等于已确认的原书章节边界，以本机页段定位为准。

成功块保持不变；失败块显示具体原因及对应AI记录，可只重试失败块，重试沿用该块上次题量。可取消并重新打开任务继续，关闭服务中断后也可继续未完成部分。网络或保存失败后的重试可能再次产生模型用量；系统不承诺供应商请求恰好执行一次。

出题结果仅为预览，可选择题目、编辑JSON并显式确认新增到待审核区。重复确认会被阻止；不会自动发布或覆盖旧题。任务显示总结、出题、失败、生成和导入数量，已保存的成功批无需重复处理。任务正文和进度随完整SQLite备份保留；普通JSON备份不包含私人AI任务及处理历史，跨设备继续此类任务使用SQLite恢复。

### AI失败记录与诊断

“AI处理记录”支持按类型和成功／失败／取消筛选，保留重试前的失败记录；教材批次可直接打开所属任务，反馈复查可返回对应反馈。列表在数据库筛选和分页，只读取当前页结果。

模型请求真正开始后发生的失败会记录错误码、失败阶段、可用的模型HTTP状态、结束原因、耗时、输入／输出字节及各次调用。可区分鉴权、限流或额度、服务异常、超时、空响应、响应封装或正文JSON错误、截断和结构字段不符合要求，并给出下一步建议。解析器提供字符位置时展示数字位置；没有位置时明确说明，不回显原文片段。

无效输入或模型尚未调用的前置校验不会伪造供应商失败记录；批任务仍展示相应失败原因。失败或取消记录没有可应用结果，不可用于判分、入库、修订或建题集。诊断不保存密钥、鉴权头、模型隐藏思考或原始错误正文。Android也会独立持久化安全失败审计；磁盘保存失败则返回507并回滚，不会把未落盘记录当成保存成功。

### AI审核和记录

待审核列表支持单题或多题AI审核。选择“无误自动通过”只对本次无疑义且通过硬校验的题生效；需要修改或不确定的题保留待审核。建议修改后仍需重新审核，不因应用修订而直接发布。

AI工作台可查看分析记录。每次评价或审核1—20题，转换最多50题；服务端转换文本最多40万字符，整体请求内容另有字节上限。模型超时可配置5—180秒。超时、网络错误、非法JSON、缺失题号、越界分数等都会明确失败，不生成假评分或残缺导入。AI解释、建议与审核结论仍可能出错，应结合来源和实际验证使用。

## 系统配置

### 外观主题

内置森林绿、暗色、淡粉色（#DDAACC）、天蓝色（#66CCFF）、薄荷绿（#39C5BB）五种主题，初始使用森林绿。在“学习与练习”的外观区域选择主题可即时预览，点击“保存系统配置”后保存；未保存就离开会恢复已保存的主题。主题随独立配置导入导出和完整备份迁移，首次加载使用本机缓存减少闪烁，数据库中的配置为准。

学习情况使用紧凑统计展示累计与判定计数，详细历史仍在主内容区。配置页按分组和屏幕宽度排列，数字输入收窄；手机上按宽度调整列数，窄屏自动单列。

系统配置集中学习与练习、文件资源、AI辅助和数据备份。修改组题默认值只影响新建/恢复默认操作，旧卷与历史使用原快照。

### 单独重置学习进度

在“学习与练习”底部点击“预览重置范围”，弹窗列出原题状态、组合小题状态、答题学习结果和复习事件数量，以及保留的历史答题和草稿数量。勾选影响确认后，才可点击“确认重置学习进度”。预览后学习数据变化时需重新预览，不会自动重试重置。

重置清除掌握程度、最近与下次复习日期、错题状态、累计答题统计、旧复习动作以及FSRS卡片和反馈事件，预览分别显示卡片／事件数量。题目、题集、收藏、整题与小题笔记、整卷历史及成绩、单题详情、作答草稿继续保留；单题详情标为重置前记录，不再计入新统计。旧历史不会在重新打开或迁移后自动恢复已重置的进度。清理历史与重置学习进度是两个独立操作，需要保留进度时可先导出完整备份。

## 每日推题

在“系统配置 → 每日推题”开启，必须选择一个领域和至少一个分类，选择父分类同时包含下级。默认关闭，不会替用户选择学习范围。只选择该范围内已发布的题目。

默认目标为复习30分、新题20分，按生成时“学习与练习”的题型默认分值计算；多选题初始默认4分。两个目标可分别修改，合计须为50—10000分。复习题不足时，把缺少的分值目标补给新题。例如复习只有10分，则新题目标为40分；新题每题3分时可选到42分，整份52分，无须精确凑成50分。新题不足时也可用剩余复习题补足。当天不重复选同一道题，组合题保留公共材料及全部小题，每次最多500个作答项、实际总分最多10000分。可用题不足时如实生成现有题目，显示缺口；完全无题时只保留提醒。

系统根据实际提交回答（包括未判分主观题）、掌握程度、复习日期或复习记录识别已经学习的题目；组合小题的学习标记可使整组视为已学。固定间隔模式优先考虑最新错误、部分正确及到期题，再考虑较久未复习的题目；新题随机抽取。仅收藏、写笔记不视为已学习，纯漏答证据不算实际作答；若已有复习日期，则按复习计划处理。

默认FSRS模式进一步只从已有计划且到期的学习题中选复习，不用未到期旧题凑足复习分值。短期学习／重学须已到具体时刻；普通间隔复习可选当天稍晚到期的题目作为日计划，实时队列仍只列已经到时的任务。顺序优先短期重学、逾期和更早到期，暂停卡片不参与；组合题有任意有效小题到期时仍按整组入卷。开启“复习积压时减少新题”后，到期复习分值超过复习目标时可将部分新题额度转给到期复习，卡片说明本次转移；不足再按现有规则补新题。切回固定间隔时仍采用原来的学习证据与复习排序。

任务默认使用Asia/Shanghai时区，每天00:00触发，可修改时间及IANA时区。网页部署需要服务运行，Windows桌面端需要应用运行；Android在应用运行时检查和保存。服务停机、手机关闭应用或系统挂起后，下次启动补当天已到时间的推送，不补所有错过日期。Android没有系统级后台唤醒或通知栏推送。考试期间暂停前端推题检查，Android延后至交卷再补推。

每日推题集中在“题集与练习”页的小卡片中，显示今日推荐、复习／新题／合计分值、未查看状态及配置入口，不另设导航栏目或独立页面。打开今日题集会标记已查看。每日生成普通计分题集，按“YYYY-MM-DD 每日推荐”命名并直接存入题集库，可继续使用练习、考试、收藏、错题、草稿、历史及导出功能。以往推荐也通过普通题集列表按日期或“每日推荐”搜索。原题集被归档或删除后，今日卡片会说明状态，停止展示失效入口。

知识总览的“今日学习建议”也提供快捷按钮：未开始时显示“开始今日推荐”，有草稿时可“继续今日推荐”，已提交且保留卷面时可“查看今日结果”。点击会标记已查看。尚未开启时显示“开启每日推荐”进入配置；尚未生成或没有有效直达目标时，可通过“查看每日推荐”进入题集页。题集归档后，仍保留的作答结果和草稿可以直接打开。

这两个入口都显示每日推荐作答进度：未开始、作答中、已提交或已完成，以及“已答N／总题数”和“已覆盖X／总分”。题集卡片另有进度条。已覆盖分值是已填写题目的满分合计，不是实际得分；答案保存后才计入进度，组合题按小题计数。全部题目填写并交卷后才标记已完成，主观题待判数量另列，不影响作答完成；交卷有漏答时显示已提交及漏答数。缺题时以当天实际生成的题目和分值为分母，目标缺口仍单独提示。

重复练习取覆盖分值最高的一次提交，覆盖相同时取已答题数更多、再取最近提交的一次，不累计各次作答。重新练习的草稿不会抹掉此前完成进度，题集卡片仍提供继续草稿入口。进度跟随当天生成时的题目和分值快照；之后修改题集不会重算原推荐，缺少原版本依据时显示进度不可用。旧推荐可从原版本题集或保留作答恢复进度依据，不会改写原记录。

清理历史卷面仍可依据保留的学习摘要显示完成进度，卷面已清理时不会再提供该结果链接。主动“重置学习进度”会清除这些学习摘要；若完整卷面也已清理，就不能恢复此前的完成情况。完整卷面仍在时，可以继续据其统计实际作答情况。

同一时区日历日期最多生成一次，重启和重复检查不会重复建题集。当天已生成后修改范围、配比、默认分值或触发时间，次日生效；关闭后已有题集与推送记录继续保留。题集及作答的分值快照保持原值。

完整JSON和SQLite备份保留推送记录及已读状态；单独配置迁移只包含推题设置，不包含推送历史。启用状态的配置导入前，目标设备必须已存在对应领域分类。发布包的基础配置保持关闭且未选择范围，领域题库分享包不包含个人推送记录。

## 备份迁移与恢复

### 单独迁移配置

在“系统配置 → 数据与备份 → 配置迁移”导出小型配置JSON，可选择是否包含AI端点、模型和请求参数；密钥始终排除。软件附带的`config/defaults.json`也是可导入的干净基础配置。

目标设备选择文件后会列出当前值与导入值，确认后覆盖当前配置。题库和笔记不受影响；调低记录保留上限可能清理超限草稿或历史，必须另行勾选确认。预览后配置或记录发生变化时，需要重新预览。AI接口相同则保留目标设备原密钥；接口改变则清除旧密钥，随后由用户重新填写。普通配置文件不会带出或导入密钥。

完整JSON备份仍按既有合并规则保留已自定义的目标配置；需要主动替换偏好时，使用独立配置导入。配置文件不能当作题库文件导入，题库包也不能当作配置文件导入。

### 各导入入口的区别

| 用途 | 格式 / 入口 | 新题状态及冲突规则 |
| --- | --- | --- |
| 批量新增 | 新题JSON模板 | 全部待审核，不覆盖既有题号 |
| 修订待审核 | 待审核导出JSON | 只更新既有pending题，核验原版本 |
| 接收他人内容 | learning-share / 分享与导入 | 补全依赖，冲突另存，新题待审核 |
| 恢复自己备份 | 完整JSON / 系统配置 | 保留原审核与学习状态，同ID已有内容跳过 |
| 整体恢复 | SQLite副本 / Android完整恢复或电脑停服恢复 | 整体替换内容、配置与学习状态，AI密钥需重填 |

完整JSON含题目、分类标签、资料、资料编辑草稿、图片/PDF、题集、作答快照、整题与小题学习记录、独立错题结果、单题答题详情、复习事件和常规系统配置。已经清理整卷历史的错题快照、保留中的单题回答和来源仍可迁移，已重置状态也会保留。导入校验失败回滚，同ID内容保留目标版本；目标设置仍为初始默认时可恢复源设置，否则保留目标自定义值。旧备份没有新字段仍兼容，但无法还原文件内已经不存在的旧历史。

完整JSON和SQLite还保留FSRS卡片、完整反馈链、当次参数及记忆状态。JSON导入会核对反馈链与卡片重算结果；同ID卡片已在本机时，整组保留本机卡片及事件，不混合两份不同版本。旧备份缺少FSRS数据时继续保留旧复习日期，不猜测补造回忆史。分享题库包不含私人卡片或反馈，单独配置文件只含调度设置。

AI服务密钥不进入JSON或分享包。JSON不携带AI私有配置及分析历史；这些分析记录可通过SQLite迁移，明确追加的AI笔记也进入普通学习记录备份。产品导出的SQLite副本会清除密钥，恢复后需重新填写，本机原库不会被清空。不要把磁盘上正在使用的原始数据库误当成已经脱敏的分享文件。

JSON导入最多80MiB。图片/PDF以Base64携带，附件多时文件会变大；个人完整备份优先使用SQLite。在线SQLite下载是一致性副本，不直接复制运行中数据库猜测一致性。

电脑完整恢复：停止学习站，把下载的SQLite放在选定位置，通过 `DATABASE_PATH` 指向它，再启动服务。Android可在“数据与备份 → 从SQLite备份完整恢复”选择数据库文件。不同设备不会自动同步，JSON合并与SQLite整体替换各自适用不同目的。

### Android完整恢复SQLite

1. 选择 `.sqlite`、`.sqlite3` 或 `.db` 文件。应用在独立副本中校验文件完整性、应用表结构、版本、业务数据、引用和成绩，显示本机与恢复后的记录数量及文件校验摘要。文件选定后固定使用已检查的字节副本；损坏文件、不支持的版本或无效引用会被拒绝，预览不替换本机数据。
2. 核对预览并勾选确认，点击“保留当前副本并完整恢复”。本机正在考试时不能恢复；预览后本机数据或数据库文件发生变化，需要重新选择和预览。备份带有未交考试时，恢复后会核对考试期限并进入对应考试。
3. 应用先把恢复前完整数据库保存为独立私有副本，再提交替换；该副本不会被后续普通保存覆盖。成功后页面重新加载，采用新库的内容、配置和学习状态。恢复保留AI端点、模型和分析历史，清除密钥并关闭AI，需重新填写和启用。
4. 校验、备份或保存失败时显示原因，失败替换会回滚。可从同一区域“最近的恢复前副本”保存或分享原库副本。私有副本在本机保留原有凭据，任何对外导出的副本仍清除AI密钥；应把需要长期保存的副本另存到应用外。

SQLite完整恢复直接读取二进制，不受JSON的80MiB限制；实际容量取决于设备可用内存和存储。卸载或清除应用数据会一并删除私有副本。当前自动化覆盖真实WASM和模拟文件桥的校验、保存及回滚，真机文件选择、分享和不同设备上的行为仍以验收记录为准。

若恢复与回滚的存储操作都失败，应用保留原内存连接和独立恢复前副本，并提示导出副本、检查手机存储；此时不会宣称磁盘已经成功恢复。

## Android使用

APK单独交付，不包含在源码或运行ZIP内。最低Android 7 / API24，构建、签名及安装方式见[发布与部署](./发布与部署.md)，实际验证范围见[验收记录](./验收记录.md)。

题库、页面、WASM SQLite和中文字体随包提供。关键写入等待手机私有文件保存成功；落盘失败会回滚，不显示假成功。系统文件选择、保存和分享由Android提供。AI需网络和自行配置的模型，日常题库、资料、组题与复盘可离线使用。

同应用ID、同签名更新可保留数据；卸载或清除应用数据会删除私有学习库，应先导出备份到应用外。手机分享文件的目标应用需已安装。当前验证包括真实WASM与模拟原生桥，真机或模拟器安装及不同机型原生交互的验证范围以验收记录为准。

## 常见问题与边界

- **为什么导入后看不到题？**新增和分享内容可能仍待审核，正式列表与组题只展示已发布题；切换状态筛选或进入审核页。
- **为什么不能删分类或文件？**仍被题目、资料、归档卷或历史快照引用；先处理引用，或保留归档。
- **为什么已开始的卷没有新修改？**它使用开始时快照；重新创建作答或保存新卷版本后再开始。
- **为什么AI没有返回结果？**先检查开启状态、端点、模型名、凭据、网络、超时与服务是否支持兼容协议；不会自动回退到未配置的其他服务。
- **为什么扫描PDF无法导题？**本机文字提取不等于OCR；先识别成文本，再检查章节和题目顺序。
- **能否作为公网多人服务？**当前是本地单用户设计。公开部署前需单独实现身份、权限、多用户隔离等，不应直接暴露本地端口。
- **能否支持大量附件？**当前所有资产在SQLite内，Android每次写入需保存整个库。大量书籍会增加内存和写盘成本；后续可保留API替换资产存储，当前不宣称验证过海量书库。

技术依据：[兼容Chat Completions接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[vLLM兼容服务](https://docs.vllm.ai/en/stable/serving/online_serving/openai_compatible_server/)、[PDF.js文字提取API](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html)。实际模型响应、文件排版和运行设备仍需按自身环境验证。
