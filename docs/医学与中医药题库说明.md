# 医学、药学与中医药题库说明

本题库按现代医学概念、现代药物、中医基础、单味中药材与饮片、传统方剂、配伍与风险辨析分别组织。药材的不同标本、别名及同一物质的粉末形态不用于重复增加数量；确有不同药用属性的炮制品单独标明。

## 如何理解药材与方剂卡

“补气、补血、温里、清热”等属于中医理论中的功效表述；现代医学的药理作用、临床疗效与风险需要相应研究证据，不能直接画等号。“无毒”如出现在传统性味记载中，也不代表没有不良反应或适合所有人。

单味药材、基准方和具体厂商的成药说明书分别对应不同对象。本批方剂参考台湾卫生福利部公布的基准方，包括传统制剂与浓缩制剂的名称区分；不能据此认为相同名称的内地或其他地区产品具有完全相同的成分、剂型及批准范围。现代药物卡按单药或固定复方分别建卡，不按品牌或盐型重复扩量；主要参考NHS资料，不能替代中国具体产品的现行说明书。

## 配伍、禁忌与资料缺口

- 七情中的“相畏”“相杀”从不同角度描述传统减毒配伍关系；“十九畏”是另一套传统配伍禁忌表述，名称中的“畏”不能混为一谈。
- 十八反、十九畏按传统理论注明；中西药相互作用另列有依据的风险或研究不确定性。体外实验、动物实验、病例报告与临床研究不能互相代替。
- 来源未列禁忌或不良反应时，卡片标明未列明或待核对，不把缺少资料写成“没有禁忌”。高风险药材另有分类与风险标签，不把整个医药领域统一标成过时。
- 受保护来源、历史用途及地区监管变化需分别核对；排除或历史化处理的条目在来源清单记录原因，不计为本批现行常用药材扩充。

本题库用于知识学习，不提供个人用药剂量、处方、炮制或自行解毒步骤。涉及现实用药时应由具资质的医师或药师结合具体产品、疾病、年龄及正在使用的其他药物核对。新导入题目进入待审核，来源核对和用户审核不等同于医学专家逐题审定。
