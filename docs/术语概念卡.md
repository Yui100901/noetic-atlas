# 术语概念卡与英文引用

本轮整理日期：2026-10-23。术语卡用于按中文名、英文名称或常用缩写回忆概念，与按场景展开的面试问答共同使用。每张卡有定义、具体例子、相近概念区别、常见误解、追问及参考回答，并保留专业来源。不是只给出缩写展开，也不把普通英语释义当作技术定义。

## 组织与查找

每个领域共用一个“术语与概念”分类根，下面按语言、类型、系统、网络、药理、生理、分析等主题归类。全局学习方式标签为“术语概念”，可与领域主题标签、难度和深度组合筛选。四类计算机/跨学科术语及后续化学、医学专项各有独立题库集合；集合引用题号，未复制原有词汇卡或物质卡。

例如术语卡会记录中文“模型上下文协议”、英文“Model Context Protocol”和缩写“MCP”，再解释连接能力、权限及版本边界。普通词义有助于理解构词，专业定义仍需结合术语语境。没有通用缩写的概念保留英文名称，专名不凭空展开。同一缩写可以在不同领域表示不同概念，必须连同全称阅读。

空别名、空英文词卡引用，以及英语搭配、例句、关联词和日语关联词的空值统一显示“无”。每张术语卡不再重复词表导入说明；引用规则与缺词处理集中说明如下。药理边界、历史驾驶失效说明、日语AI来源提示及资料缺失等实质信息继续保留。“无”表示该栏目当前没有收录内容，不表示现实中不存在相应知识或关系。

难度D1—D4、深度L1—L4和频次使用原有结构化字段。非计算机内容通常不标面试频次；计算机的F值如有填写只是编辑建议，不是招聘命中统计。普通词头、技术词义、缩写和跨学科译名允许存在不同表达范围，卡片的辨析栏会说明这些限制。

已核对同领域主名唯一，跨领域缩写保留独立含义。例如AST既可指抽象语法树，也可指天门冬氨酸氨基转移酶；CI可指持续集成或置信区间；PK可指主键或药代动力学；ADR可指架构决策记录或药物不良反应。检索缩写后应结合卡片全称及领域选择。

## 英语词卡引用

解析末尾“英文单词参考”优先关联现有开放英语词表的完整词头或构词。例如已有`dependency`和`injection`时可分别查看；对`learning → learn`这类有限、明确的词族关系，另标“词族参考”，不把派生词和基础词说成完全同义。

链接使用`#/vocabulary/<词头>`，点击后按名称查找本机英语卡片：

1. 找到一份词卡：直接展开普通英语释义和用例，保留其发布状态，可返回上一页。
2. 找到多份词卡：列出各版本，用户选择；不会静默覆盖已编辑的内容。
3. 本机没有该词或尚未导入英语词表：显示缺失提示及可用搜索入口，原术语卡的专业解释仍保留。以后导入词表后可继续使用该链接。

题号重映射不影响按词头查找。领域重映射时会识别现有英语领域；接收方连英语领域都没有时，搜索入口也不强行使用不存在的领域ID。词头两侧使用一致的Unicode NFKC及大小写规范化，支持重音和全角等形式。引用页不复制词卡，不自动导入外部内容，也不自动审核词条。

当前开放英语词表并不包含所有专业派生词，因此部分卡片只有专业来源或注明的词族参考，不虚构“全部英文词均已收录”的覆盖率。英语原卡片的许可、署名和来源继续保留。下载、导入与来源总览见[题库内容与来源](./题库内容与来源.md)。

## 化学与医学边界

化学术语介绍物质结构、化学键、立体概念、计量、平衡、热力学、动力学、分析与材料等原理，配概念性例子。它与已有具体物质性质卡分别组织；术语定义不构成实验配方或危险操作步骤。

医学术语覆盖药学、生理、病理、症状体征、检验影像和研究统计。区分例如时间关联的事件与经过因果评价的药物反应、检验性能与个体确诊、风险比与优势比等。逐卡保留NIH、FDA、WHO等专业来源；内容用于概念学习，未声称经过医学专家逐条审定，也不提供个人诊断、剂量或处置方案。

医学基础术语不按领域默认标为“可能失效或过时”。例如高血压概念卡说明引用阈值应注明指南，并未给出固定诊断数值；ROC卡中的阈值是统计参数，也不据此判定过时。涉及具体版本、地区和时间的临床或监管结论时，才根据实际内容与来源证据标记。

## 构建和审核

构建源位于`scripts/content/terms-*-catalog.mjs`，共用生成器为[term-builder.mjs](../scripts/content/terminology/term-builder.mjs)。构建时先使用现有英语词表生成可迁移词头引用；缺少英语构建包时仍可生成术语卡，引用覆盖率会如实降低。

```sh
node scripts/content/terminology/terms-programming.mjs
node scripts/content/terminology/terms-systems.mjs
node scripts/content/terminology/terms-ai.mjs
node scripts/content/terminology/terms-domains.mjs
node scripts/content/terminology/terms-chemistry.mjs
node scripts/content/terminology/terms-medicine.mjs
node scripts/content/terminology/terms-medicine-clinical.mjs
npm run content:validate
npm run content:import -- --packs terms-programming,terms-systems,terms-ai,terms-domains,terms-chemistry,terms-medicine,terms-medicine-clinical
npm run content:package
npx tsx scripts/qa/audit-terminology.ts
```
