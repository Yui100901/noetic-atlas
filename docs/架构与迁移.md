# 认知星图 1.0 架构与数据交换

日常操作见[使用说明书](./使用说明书.md)，维护约定见[开发与维护](./开发与维护.md)。本文描述当前实现，不依赖原始资料目录或其他版本文档。

## 运行结构

桌面端由 React/Vite界面调用 Fastify API。业务通过 Store、读取模型与 Kysely 类型安全查询构建器访问数据，底层驱动只在 `server/database/` 适配层中使用。生产服务同时提供静态页面和API，页面可迁移，数据路径可独立设置。

Android以Capacitor承载同一界面，使用sql.js执行SQLite，再经原生文件接口持久化。移动构建替换Node文件、SQLite、HTTP和分享适配，共用路由、Zod校验、引用约束、组题与评分规则，不在手机中启动Node服务器。

SQLite使用实体表保存JSON，数据库保证主键和JSON有效性，复杂引用由事务业务层验证。当前采用DELETE日志模式，便于保持单文件备份。列表可分页；分类树与跨页选择使用共享交互组件。

题库与题集列表使用可重建的读取投影；题目筛选、计数、分页和学习状态关联由数据库执行，只返回当前页正文。全文搜索使用预先规范化的文本；词头、资源引用、题目状态等分别建立查询索引。原文、题集和作答快照保持为权威数据，持久化脏队列随原记录写入、删除和事务回滚同步，其他连接导入后也会刷新。详细边界见[查询性能与数据库访问](./查询性能与数据库访问.md)。

## 实体与边界

| 实体 | 责任 |
| --- | --- |
| `Domain` | 可扩展的知识领域 |
| `Category` | 领域下的任意层级分类；防环、父子同领域 |
| `Tag` | 领域主题、自定义标签或跨领域学习方式 |
| `Question` | 题干、答案、解析、来源、题型、难度/深度/常见度、分类标签及审核状态 |
| `QuestionPart`、`BlankSpec` | 共用材料内的小题，或有序填空及文字别名、大小写和空白规则 |
| `Document` | Markdown正文或PDF附件、领域分类、资料类型及作者等书目元数据 |
| `Asset` | 文件字节、MIME、大小、图片尺寸与受控资源引用 |
| `Paper` | 统一题集：选题方式、组织归属、顺序、版本、题目快照与可选计分配置 |
| `PaperDraft` | 尚未保存为题集的组题状态、选题、分值、筛选和版本戳 |
| `Attempt` | 独立作答快照、答案、时间、考试期限、客观成绩及主观评分 |
| `Study`、`StudyPart`、`Review` | 整题收藏与公共笔记；普通题或独立小题的掌握、笔记、错误统计、复习到期与复习事件 |
| `LearningResult` | 独立于整卷历史的来源判定、错题叶子快照及显式重置标记 |
| `QuestionHistory` | 按原题与小题限量保留的答题索引；整卷已清理时保留该叶子的快照及回答 |
| `SystemSettings` | 保留上限、默认组题分值、考试时长、上传限制和复习规则 |
| `AiSettings`、`AiRun` | 私有模型配置、分析结果、警告、版本与显式应用状态 |
| `SharePackage` | 不含私人学习状态、携带完整内容依赖的交换封包 |

领域表示学科，分类表示知识结构，标签连接主题，题集组织用户选取的学习内容与版本快照。资料的“书籍/笔记”等类型与“PDF/Markdown”格式独立。难度、深度和常见度保留为结构化字段，不能冒充题目质量保证。

旧 `QuestionBank` 类型和 `question_banks` 表只保留兼容迁移入口，不再提供集合管理接口或前端模块。启动旧数据库、导入可信JSON或旧分享包时将集合按原顺序转换为无分题集；保留完整题目，不按500题拆分，重复导入依迁移标记复用。含未发布题或空集合先归档，旧 bankId 筛选随之清理；当前题目、学习记录与已有作答快照不变。

## 题型、快照与计分

叶子题型为判断、单选、多选、填空、简答、论述；组合题用公共材料组织多个叶子小题。父题承担分类、标签、整组收藏与公共笔记；每个小题用稳定partId独立保存掌握、笔记、错误统计和复习日期。`study_parts` 的主键编码为JSON元组 `[questionId, partId]`，`reviews` 可带partId，旧整组事件继续保留而不广播为各小题已复习。

题集按父题选题并冻结完整快照。作答时展开为 `parent::part` 叶子，保留公共材料与源题关系。父分值用整数最小单位按权重和最大余数分配，保证子题合计精确。题集及迁移保留完整内容；每次作答最多500个展开作答项。大型题集开始前必须指定 count 与 selection，按顺序或随机选题，不静默截断。普通随机生成与AI推荐仍限制单次500个展开作答项。

客观题判分只使用快照中的答案规则，多选必须全对，填空按顺序逐空核对别名，不把别名当正则表达式。主观分的 `null` 表示未评，`0` 表示已评零分；全部主观题评分完成后才产生最终总分。掌握度0—3与题集分数独立。

未交卷的作答题目由服务端白名单输出，不含参考答案，不能通过CSS隐藏替代协议隔离。修改原题、删除源卷、变更默认配置不会改变已保存的作答快照。

作答组件仅消费会话快照与当前回答，不挂载原题学习编辑器、不额外读取原题笔记或累计统计。笔记编辑限定在题目查阅和题集看题组件；随机自测只有用户显式查看解析后才读取参考内容。查阅页的“学习情况”使用轻量统计接口，详细历史展开后独立分页读取，并传`summary=false`避免再次计算累计统计。

题集看题使用 `/api/papers/:id/questions/:questionId` 返回的题集快照，不跳转路由。共用阅读组件保留列表分页，上一题／下一题在当前筛选结果内移动。普通题状态按存活源题ID保存，组合小题还需校验partId与当前小题题型；源题或对应小题缺失则只读旧快照。组内重排不改变小题身份，整组收藏仍共享。题集快照内不调用原题AI解析，避免请求或缓存串用不同版本；AI解析在知识题库中针对当前原题使用。

## 练习、考试和草稿

普通练习保存开始时间并显示顺计时，提交时固化秒数。离开后恢复沿同一开始时间累计。考试保存模式、时长和绝对期限；默认120分钟，开始前可修改。

全局守卫在启动和恢复前核对进行中的考试，限制应用内导航、搜索与历史回退，并提示关闭页面；不能把客户端守卫视为服务器认证。服务器同时限制其他功能API，仅放行当前作答、期限同步、启动状态与题目资源读取。服务器始终检查期限，逾时保存或提交不会合并迟到答案，而是按到时前保存的答案交卷。同步操作幂等，自动交卷记录期限、用时和标记。

答题卡作答中区分未答、已答；交卷后使用服务端同一判题规则给出未答、正确、部分正确、错误、未判定。已答主观题未评分为未判定；计分判定区分满分、部分分和零分，无分主观题可显式应用正确、部分正确或错误，不生成分数。错题巩固仍包含部分正确结果。

作答草稿按来源和题集保留，组题草稿按编辑上下文保留，默认各3份。继续更新原草稿ID，重新开始才创建新记录。进行中的考试不参与普通草稿裁剪。已提交历史默认不限量；降低上限若会删除记录，保存配置前显示具体数量并确认，数量变化需重新确认。

题集与随机／单题通过共用的 ContextLearningPanel 和 `/api/learning/*` 接口分别组织草稿、历史、错题与复习，不再设置全局学习记录页面。按上下文查询摘要与分页记录，历史列表不加载完整题目和答案。错题由本上下文每个叶题的最新已判结果确定，正确后移出，未判不覆盖上次已判；主观题撤销评分后回退至此前有效判定。判定顺序使用提交时间，重新评分的updatedAt不会把较早提交变成最新作答。收藏和到期关联存活原题或小题的共享状态。源题集永久删除后，保留历史或独立错题的来源仍可访问。

`learning_results` 在交卷和人工／AI应用评分的同一事务内更新，并在历史裁剪前保存证据。每条结果保留来源、题集标题与版本、作答时间和轻量叶子判定，仅对错误或客观漏答叶子保留完整题干、公共材料、答案及解析，不复制整卷用户答案和成绩。历史上限只删除Attempt，学习结果、累计错误、来源、复习安排与事件继续保留；原题删除也不会清除错误快照。升级或可信导入会从仍存在的提交补建缺失结果，升级前已经删掉的历史无法补回。

`learning_results.items.answered` 持久化实际填答标志，累计统计只计 `answered=true` 的已提交叶子，按 `correct / partial / incorrect / ungraded` 汇总；漏答和纯空白排除。重评分只替换同一作答的判定。旧结果缺少该标志时，仅可从仍存在的原作答核实；整卷已清理的主观结果不从评分猜测填答，查询返回 `summary.unknown` 说明统计覆盖缺口。

`question_history` 与累计证据分别存储。该表按原题及稳定partId记录已实际填答的作答引用，默认 `maxQuestionHistory=10`，0关闭独立详情；整卷保留默认0表示不限。正常条目只引用已有Attempt，不重复保存题干和用户答案。整卷裁剪前，仅为仍在单题保留范围内的条目转存完整叶子快照与回答，组合小题包含公共材料。单题超限删除独立条目及其归档正文，不修改原Attempt或累计证据。`GET /api/questions/:id/history` 分页读取这些详情，并返回独立于详情数量的累计汇总；查询没有补写副作用。

`learningMetadata` 合并独立结果与没有结果的旧作答，避免同ID重复计数；来源以 `[source, paperId]` 隔离，叶子以 `[sourceQuestionId, leafId]` 作为JSON元组身份，不能按 `::` 拆分推断归属。`historyAvailable` 指明整卷是否仍存在，清理后保留来源与错题阅读，同时去掉失效的整卷复盘链接。统计读取轻量元数据，正文仅为当前页选中的叶子读取，读取接口不补写学习结果或刷新脏投影。

独立重置使用 `/api/learning/reset-preview` 的记录数量与指纹，`POST /api/learning/reset` 在事务中重新校验新鲜度。重置清空整题和小题掌握、复习日期、累计答题统计、复习事件及独立判定，保留收藏、笔记、题目题集、历史成绩、单题详情和草稿。仍保留的已提交Attempt对应空结果重置标记，阻止读取兼容回退、重启补建和迁移把旧进度复活；单题详情标为 `beforeReset`，这些标记随可信备份迁移。重置与清理历史分别提供明确入口。

固定汇总题集是动态读取视图，不占用普通Paper身份。`global-learning.ts` 汇总各来源判分与原题学习状态，`learning-state.ts` 共用复合身份及判分规则。全局错题按原题与叶题去重，来源各自维持最新已判结果并保留完整溯源，避免跨题集答对误清除其他来源错误；收藏和到期以当前原题为准。卡片仅对当前页执行一次批量统计，汇总页分页加载正文。来源关系与快照正文分开，错题使用最近错误快照，收藏采用当前原文。

## AI处理管线

AI默认关闭。用户配置服务端点、模型及只写密钥，按操作主动发送题目、参考解析、答案或预览过的文件文本。桌面和原生使用同一业务协议，通过可替换传输适配调用兼容模型接口。

模型结果先经结构、范围、版本和引用校验，再保存为独立运行记录。解析可补充解释、追问与误区；主观评价接受额外判题要求，给出正确、部分正确或错误及改进意见，计分卷另给建议分，无分卷应用判定；导入生成结构化待审题；审核提供判定或修改建议；推荐组题只从允许的已发布候选题中选择已有题号，并说明理由。

推荐管线由 `server/modules/ai/planner.ts` 实现：先通过公共查询层获取题目元数据，以可选手动筛选限定硬范围，再从提示词识别数量与知识要求、检索排序、截取摘要并按字节预算分批选择。小范围且显式给出数量的请求可直接交给选题阶段理解要求；省略数量时从要求识别，仍未指定则默认20。手动数量优先，范围取交集；不因候选超过300题拒绝，不把全库正文传入模型。单次推荐数量上限为500个父题，同时最多500个展开作答项。跨批去重、已有题号和源版本由本地代码核对，全部批次成功后才保存完整推荐；结果统计区分可用范围、匹配题量、实际比较候选及批次数。

`server/modules/ai/execution.ts` 统一生成任务的执行边界，`shared/ai/ai-progress.ts` 定义 `status / delta / result / error`。Web和Windows桌面通过SSE接收真实阶段及模型答案片段，进度不代表已写入；结构及版本校验、数据库写入成功后才发送最终结果。提供商层解析真实分块、限制字节数，仅转发答案文本，不转发隐藏思考或原始诊断。AbortSignal沿客户端、执行层和提供商传递，异步返回后与落库前再次校验取消状态，防止未完成任务保存或自动发布。

Android通过同进程订阅获得相同阶段事件，生成接口仍返回完整JSON，保留 `mobile/runtime.ts` 的串行写入、文件持久化与失败回滚边界。当前原生HTTP适配缓冲完整响应，展示真实阶段而不伪装逐字流；取消后忽略迟到响应。原生网络通道后续若支持真实分块，可通过传输能力标记接入，业务与事件协议不必复制。

应用评分、追加笔记、确认审核或保存推荐卷均为显式动作。AI不能改写客观判分、绕过题目审核，或静默扩大题量与范围。未发送的图像、资料缺失或不确定输出须保留警告。

## 新增、分享与可信迁移

| 通道 | 用途 | 新题审核 | 分类与附件 | 用户状态 |
| --- | --- | --- | --- | --- |
| 单题或批量新增 | 用户录题、格式转换 | 统一待审核 | 引用现有分类标签；可配合AI建议 | 不导入 |
| 内容分享 | 单题、筛选题目或题集交换 | 新增统一待审核，相同内容复用本地状态 | 携带领域、祖先分类、标签和图片依赖，冲突重映射 | 不携带 |
| JSON可信备份 | 合并迁移已有学习数据 | 保留原状态 | 校验完整引用，同ID已有内容不覆盖 | 包括学习记录、快照等白名单 |
| SQLite备份 | 整体搬迁和恢复 | 保留数据库状态 | 同一文件携带附件字节 | 保留完整业务数据，下载副本清除AI密钥 |

分享预览与实际导入使用相同依赖规划和版本指纹。相同语义尽量复用，不同内容发生ID冲突时另存并同步改写分类、标签、图片、题号和分值键。含待审题的题集先归档，待题目确认后再恢复。

可信JSON备份还包含系统配置、编辑草稿、studyParts、learningResults、questionHistory和带partId的复习事件，已清理Attempt的错题证据、保留中的单题归档与reset标记不依赖原会话存留。旧备份缺少新增数组时默认空集合，再从其中现存Attempt补建；导入校验单题索引与引用作答的一致性，失去原作答的条目必须携带完整叶子及回答。默认配置的目标库可恢复源配置；已有自定义配置的目标保留本地配置。AI私有配置和分析历史不进入JSON白名单，用户明确保存到整题或小题学习笔记的内容按普通笔记迁移。

合并迁移在事务中校验ID、分类环、作用域、附件、题型、历史快照和成绩，任何错误整批回滚。正常软件安装无任何种子内容，不自动读取本地旧`seed.json`。独立配置迁移使用严格配置Schema、差异预览及新鲜度指纹，明确确认后可覆盖自定义偏好；AI密钥不参与文件迁移，端点变更会清空旧密钥。配置和可能的保留清理共用事务，失败全部回滚。

## 文件、导出与持久化

上传MD转换为UTF-8正文，PDF与受支持栅格图片保存为SQLite资源。引用保护覆盖题目、资料、整题与小题笔记、题集、历史快照、独立错题快照及单题归档中的题目和回答；仅被已清理整卷历史留下的单题引用的资源同样不能删除。解除全部引用后，未被其他内容使用的资源才可删除。

卷面导出先构造统一结构，再生成Markdown或嵌入中文字体的PDF。空白卷不包含答案，完成卷使用保存的作答快照；本地图片随文件导出，不依赖原服务地址。远程图片不会自动获取。

在线SQLite备份使用一致性API，在独立副本清除AI密钥并清理旧页，原库不变。原始数据库直接复制仍可能包含凭据，备份应由用户私有保管。

移动运行时将读写串行化。写操作先完成业务事务，再保存SQLite字节；保存失败恢复同一内存数据库对象并返回失败。GET没有写副作用，考试期限处理通过显式POST持久化。APK仅含程序、干净基础配置、WASM、字体和许可证，不含预装题库、用户库或密钥。

Android完整恢复由 `mobile/restore-validation.ts` 与运行时专用方法处理，文件字节不进入JSON路由，也不受JSON的80MiB请求上限限制。选定文件先冻结不可变副本，在独立虚拟数据库中检查SQLite文件头、integrity_check、外键、核心表结构、应用版本、JSON主键、业务Schema、引用及成绩；移除导入的触发器和派生缓存，再由可信代码重建。通过空Store校验完整业务数据，避免同ID跳过掩盖损坏记录。AI私有配置与运行记录另行验证，恢复副本清除密钥并关闭AI，保留端点、模型和分析历史。

预览展示原库与目标库计数、SHA-256及未交考试数量，并绑定运行时写入版本与原库磁盘字节。当前未交考试会拒绝恢复；本机写入或外部文件变化使预览失效。确认操作与普通读写共用串行队列，先落盘独立恢复前副本并回读核对，再替换同一内存连接和主文件；任何保存失败恢复原内存与磁盘，独立副本保留以供导出。正常保存使用临时文件和前一版本轮换，不能覆盖独立恢复副本。成功后要求刷新，阻止旧页面继续写回过期草稿。

恢复前私有副本保留原库全部内容和本机凭据，对外保存或分享时仍经过脱敏副本流程。恢复后备份中的未交考试由正常同步与守卫接管。自动化可验证真实sql.js、模拟文件桥、版本拒绝和失败回滚，不能替代Android真机的文件选择、存储、分享和安装验证；容量与性能仍受设备内存及整库保存成本约束。

## 本地服务边界

当前定位为本地单用户学习工作台，不提供多用户身份与权限体系。服务校验Origin并限制跨站写入，只开放编译静态根。部署到外部网络时，应由部署者提供认证、TLS与访问限制。

Markdown不执行原始HTML，不自动读取外部URL。AI文件处理只读取用户选定并预览的内容，模型输出不能变成文件访问或任意工具调用。

SQLite/WASM 已有实际执行与持久化回归；PostgreSQL/MySQL 当前只验证通用查询的方言编译及参数化，尚未提供可运行的连接配置。更换数据库需要实现执行器、JSON/数组及排序表达式、迁移和事务语义，再进行实库验收；不能仅凭查询构建器宣称可直接切换。将来引入 FTS 或独立附件存储时，也须保持数据交换协议及跨端一致性。
