# 认知星图 1.0

1.0 是认知星图的首次正式发布基线。本地单用户使用，支持 Web、免安装 Windows 桌面端和 Android，覆盖资料学习、题库整理、练习自测、复习计划及可选 AI 辅助。后续以小版本修复和优化为主，保留用户学习数据。

- 题库支持自定义领域、分类标签、审核与质量维护；精确重复题复用，近似题由用户核对差异并决定保留方式。
- 题集统一浏览、练习、考试、草稿和作答历史；支持客观判分、主观评价、组合小题及双向词卡，题集快照保留作答时的内容与判题要求。
- 专注复习、FSRS 到期队列、多领域计划、时间预算、周目标及综合统计形成持续学习流程；清理历史卷面与重置学习进度分别操作。
- Markdown／PDF 资料、文字 PDF 全文搜索、固定版本的题目原文关联、本地公式与专业表达支持阅读和复盘。
- AI 支持解析、主观判题、编辑建议、题目审核、资料分块出题及推荐组题；结果经校验和确认后应用，保留用量与失败原因。
- 后台任务支持切页继续、进度通知、取消重试和结果恢复；内容分享统一使用带清单的数据包，整体或领域迁移使用 SQLite 并保留相关学习记录。

软件包为空题库，仅带干净基础配置；AI 默认关闭，没有个人端点或密钥。可选领域题库包作为独立附件提供。版本、文件摘要和 Android 公开签名信息以本次发布报告为准；Android `1.0` 对应 `versionCode=10000`，后续 `1.0.1` 为 `10001`、`1.1` 为 `10100`。

此前使用过的 1.x／2.0 编号属于开发期记录，原 3.0 定版计划已并入本次首发，不作为正式升级链。现行数据格式与保数据更新以 1.0 为起点；退役的页面跳转、独立集合转换和旧JSON封包命令已移除，当前学习库、SQLite备份恢复及正常小版本更新保持独立。

2026-11-10 软件候选 `5f6488a206b192201a64d9f5b532e6f48fdaa2e8` 修复 Android 原始 SQLite 被系统文件选择器置灰的问题。全量 1,418 通过、4 项缺可选内容文件跳过、0 失败；新实际 Windows EXE 13 组、独立 Web 运行包 7 组及 Windows 整体／领域恢复 2 组通过。

雷电 Android 14 的初轮基线与新候选六项回归分开记录，随后同一正式 APK 在荣耀 PPG-AN00／Android 16 真机补齐真实离线、英文 PDF 两页画布与搜索定位、草稿／暂停计时／交卷／重开检索及迁移分享核对，恢复网络后另验证嵌入中文字体的两页渲染。真机使用约 1 MiB、21 道原始题的合成库，不作为最大题量或所有 PDF 类型的容量承诺；暗色状态栏对比度偏低列为轻微观察。Docker 仅生成构建命令。

完整范围、打包中断恢复与未测条件见 [1.0 发布清单](./1.0发布清单.md)和[验收记录](./验收记录.md)，安装与保数据更新见[发布与部署](./发布与部署.md)。这些构建后记录不修改已封存软件包，最终公开发布仍需单独核对题库附件和发布步骤。
