# 认知星图 1.5.0

本次更新集中完善学习流程、AI可靠性、数据保留和跨端体验。软件继续采用空题库安装与独立内容包，现有数据升级前应先备份。

- 题集统一组织练习、考试、草稿、历史、错题、收藏和待复习任务；题集内使用独立看题页，保留返回位置和上下题顺序。
- 单题累计统计与最近完整作答分开保存，组合小题独立掌握与复习；清理历史卷面保留必要学习状态，重置学习进度另行操作。
- 接入FSRS-6自适应复习、每日推荐进度、本周学习统计及统一搜索；概念卡与词汇卡支持题集内双向练习。
- AI支持编辑建议逐条应用与撤回、主观题评分要求及正误判定、相似题推荐、多文件教材分块总结与分批出题、工作台草稿恢复、流式进度及具体失败诊断。
- 质量管理按题目汇总反馈与扫描证据，各项问题独立处理；审核和编辑保留筛选上下文，字段规则与质量扫描保持一致。
- 修复普通练习离开后持续计时、保存失败时离开丢失输入、人工阅卷未保存保护、审核切换筛选误选旧题、教材候选图片引用保护和Android只读操作误写回整库。
- 手机组题使用底部已选与完成操作条；题目、资料和系统配置提供持续可见的保存区，AI导入优先展示输入，资料低频筛选收进高级条件。
- 收敛服务模块、查询与AI持久化契约、页面复用组件及样式归属；测试复用编译代码但保持数据库隔离，加入格式检查和CI。
- 发布清理同时保护旧版混放的内容包，先核对SHA256归档再清理软件，遇到冲突停止。
- 提供Web源码与运行包、免安装Windows桌面包、使用原正式证书签名的Android APK，以及Docker构建命令。各端版本统一取自package.json，Android 1.5.0的versionCode为10500。

软件包仅含干净基础配置，AI默认关闭，不含个人端点、密钥、工作数据库和学习记录。独立题库包仍需单独导入与审核。
