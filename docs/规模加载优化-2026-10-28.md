# 规模与加载优化（2026-10-28）

本轮针对题集数量增长和首次加载优化，保留现有题目、学习记录、计分、草稿及导航规则。测试均使用合成数据或隔离内存数据库，未访问实际工作库。

## 题集读取

题集列表改用`GET /api/papers/page`。领域专项、归档、标题搜索和分页均在服务端执行，默认每页20份，可选10／20／50／100。返回卡片所需的题数、版本、简介和计分摘要，不返回成员题号、题目快照、完整筛选及逐题分值表；卡片简介最多1000字符，详情仍保留全文。

查询使用现有数据库层和Kysely参数绑定。按更新时间降序、原始插入次序稳定排序；先定位当前页ID，再读取该页摘要，避免深分页排序携带大量JSON。增加活动状态／更新时间及领域／更新时间索引。标题包含搜索仍需检查候选标题，不宣称采用全文搜索索引。

界面保留原筛选、每页数量和返回位置。越界页收敛到有效末页。学习摘要仅请求当前页ID；慢请求期间隐藏旧页卡片，不将旧响应的页码用来重置新分页，迟到请求不能覆盖新条件。

作答页通过`GET /api/papers/:id/metadata`核对当前题集是否存在，替代下载全部题集。这一路径只读取ID、名称、版本及归档状态，不展开题目、计分或快照；仅404视为题集已删除。

旧`GET /api/papers`接口继续保留，主界面不再用它枚举全部题集。接口契约随启动生成的OpenAPI更新，Web、Windows与Android复用相同业务实现。

## 按功能加载

题库、题集、作答、资料、AI、统计、设置、手册等功能页面使用React.lazy与Suspense。顶部搜索控件和结果页分离，共用轻控件不再静态加载Markdown解析器；需要展示Markdown时再加载其渲染模块。PDF读取、导出和字体继续保持按需加载。

考试全局守卫继续常驻。题目未保存保护在路由切换前执行，取消离开时不加载目标功能；AI工作台切换前仍保存草稿。功能代码加载失败显示“页面功能加载失败”及“重新加载应用”，由用户手动恢复，不自动重复刷新。已经访问的模块可由浏览器复用。

## 测量方法与边界

最终构建与单独执行的合成基准结果：

| 项目 | 优化前 | 优化后 |
| --- | --- | --- |
| Web启动静态JS（含预加载） | 1,008,362字节 | 297,563字节，减少70.49% |
| 对上述JS本地gzip估算 | 305,461字节 | 97,150字节，减少68.20% |
| 5000份题集目录响应 | 22,331,653字节（全部） | 67,859字节（20份卡片），减少99.696% |
| 同一基准的暖HTTP请求中位数 | 1437.396毫秒（全部） | 14.279毫秒（20份卡片） |
| 深第200页中位数 | 未单独测旧客户端分页 | 19.091毫秒 |
| 领域筛选20份中位数 | 未单独测旧接口 | 60.136毫秒 |

5000份题集首次建立投影用了8286.382毫秒，另有合成数据生成耗时，均没有隐藏到暖查询中。该场景刻意使用带25题快照与较长说明的题集；缩短响应规模的收益不能当作相同数据量下数据库执行速度的对比。525份浏览器夹具的默认20条响应为18,506字节，随卡片说明长度变化。

Android功能页面同样分块，但离线应用仍需加载本机SQLite业务运行时，最终静态JS约1.24MB；未保存旧移动构建基线，不给出移动端体积减少比例。本轮未在Android真机测启动耗时。

`scripts/qa/check-loading-chunks.mjs`读取构建manifest并累计入口的整个静态JS依赖图，包括预加载块；同时确认AI、题目、统计、手册和Markdown解析器不在启动静态图中。gzip为本地压缩后的体积估算，不能等同当前HTTP传输已开启压缩。此统计不包含API、CSS、字体、动态功能块或Android首次数据库初始化。

`scripts/qa/check-paper-scale.ts`生成5000份、每份25题的题集，含正文快照、成员及分值信息，比较旧全量接口与新20条卡片分页。分别预热并重复5轮，另记录深第200页和领域筛选；投影首次刷新成本单独记录，不混入某一侧的暖查询。进程内HTTP耗时不等于真实设备、磁盘或网络时延，也不承诺每次请求固定毫秒数。

现有派生投影在首次建立、失效或大量导入后仍需处理相应数据；按需加载优化下载与执行范围，并不能消除这些初始化成本。完整快照及恢复数据没有缩减，发布数据规则保持不变。

验证结果：849项自动化测试、54组浏览器专项及306个全页面布局样本通过，Web与Android网页资源构建和静态依赖检查通过。全页面回归发现并修复了首页卡片样式对手册模块的隐式依赖，避免懒加载后出现卡片粘连。完整证据见[验收记录](./验收记录.md#2026-10-28-规模与按需加载)。

## 复跑

```powershell
npm test -- --test-concurrency=4
npm run build
node scripts/qa/check-loading-chunks.mjs
node scripts/qa/check-scaled-loading-ui.mjs
node --import tsx scripts/qa/check-paper-scale.ts
npm run mobile:build
node scripts/qa/check-loading-chunks.mjs --mobile
npm run docs:check
```

浏览器脚本需要Playwright和本机浏览器。构建必须顺序执行；浏览器运行期间不要清理或重建`dist/web`。性能测量应在构建、全量测试及其他重任务结束后单独执行。报告位于被Git忽略的`test-results/loading-scale-*.json`、`paper-scale/`及`scaled-loading-ui/`。
