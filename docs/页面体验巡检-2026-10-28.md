# 页面体验巡检（2026-10-28）

本轮逐类检查主要页面、返回路径、操作入口及响应式布局，并修复能够明确复现的问题。当前复验样本没有页面加载错误、横向溢出或卡片间距告警；这不代表所有数据组合、设备和异常流程都已穷尽。

| 模块 | 覆盖内容 |
| --- | --- |
| 总览与导航 | 总览、全站搜索、手册、侧栏跳转与返回 |
| 知识题库 | 列表筛选、各题型详情与编辑、新建、导入、审核、未保存笔记与编辑保护 |
| 题集与练习 | 题集列表、创建方式、手动与随机组题、详情、独立看题、学习页签、作答草稿与已交卷结果 |
| 学习汇总 | 全部错题、收藏、待复习、独立阅读、随机与单题自测记录 |
| 内容管理 | 质量问题列表、带问题的编辑页、反馈核对、领域分类标签 |
| 学习资料 | 列表、新增、Markdown编辑与阅读、PDF阅读、编辑返回与资料草稿 |
| 辅助功能 | AI工作台各页、AI配置开关提示、AI工作流回归、分享导入 |
| 设置与统计 | 五个设置分区、五套主题、空库、按周／日／月／自定义／年范围统计 |

全页面扫描覆盖67个页面／状态，在1440、1024、390、320像素宽度检查；另检查15个空库页面的桌面和手机布局、五个主题，共306个布局样本。截图复查重点包括设置、题集、质量管理、题目、资料和AI导入。几何检查包括横向溢出、相邻卡片、按钮与分隔线、页尾间距、同目标的重复页头动作及可见加载错误。

## 已完成的优化

| 问题 | 调整后的行为 |
| --- | --- |
| 题集与资料返回时丢失筛选、分页 | 列表状态写入受限URL；详情、编辑、新建取消或保存后可回到原位置。题集常用返回链接还可恢复当前标签页的列表状态。清空筛选时保留每页数量并回到第一页。 |
| 题集创建方式平铺，入口较分散 | 手动与随机创建合并到“创建题集”主按钮及下拉菜单；保留醒目的“AI推荐题集”和“随机抽一题”。领域分组数量明确标为“本页”数量。 |
| 随机练习历史入口先出现无关的空题卡 | 历史／草稿深链优先显示记录，抽题筛选默认收起；未交卷返回草稿，已交卷返回历史。手机页签换行，避免当前页签被截断。 |
| 题目编辑及普通看题笔记缺少统一离开保护 | 正文、归类、已应用AI建议和笔记未保存时，返回、侧栏、管理链接及浏览器返回均提示；取消后保留当前输入。成功保存后的正常跳转不重复提示；取消开始自测不创建多余草稿。 |
| 反馈核对展示不完整或混入错误答案 | 复用管理题面预览，包含选项答案、填空及组合小题；小题未设置解答时不再错误回退为父题答案，不混入学习操作。 |
| 题库筛选、领域新增、AI配置入口有重复 | 题库内容属性由顶部页签控制，不在高级筛选重复；领域新增只保留顶部入口；AI关闭时各页只显示一个合适的配置入口，开启后隐藏配置提示。组题所需完整筛选仍保留。 |
| 设置切换分区丢失尚未保存的输入 | 分区首次访问时挂载，后续切换保留表单；隐藏分区不占布局，也不能获得键盘焦点。页面说明保存与刷新规则，切分区不会自动写入配置。 |
| 资料编辑返回按钮文案与实际目标不一致 | 编辑页明确“返回资料详情”，并保留后续返回列表的筛选上下文。 |
| 纯文本手册文档显示空目录 | 无二级标题的文档作为完整章节展示，支持正常阅读和搜索空结果提示。 |
| 弹窗Escape读取旧的忙碌状态 | 关闭逻辑读取当前状态；处理期间不能误关。仅最上层弹窗响应键盘，Tab只经过可见、可用控件，排除折叠内容；嵌套弹窗共用滚动锁，关闭后恢复焦点和背景滚动。手机关闭热区至少44像素。 |
| 质量问题行重复出现“用户反馈” | 来源保留一份徽标，不再额外重复相同的问题类型文字。 |

以上修改复用已有导航保护、题面预览、共用弹窗和布局规则；列表上下文解析分别限制允许字段及长度，不接受任意外部返回地址。

## 验证结果

- 全量自动化测试830／830通过；最后的弹窗过滤及展示微调另做11项针对性测试。
- 55组浏览器专项通过：题目导航9、题集交互6、资料与设置导航8、手册及AI提示5、资料草稿7、既有AI工作流16、弹窗交互4。
- 全页面306个布局样本通过：无横向溢出、间距告警、可见加载错误、浏览器未捕获异常或外部请求。
- Web构建、Android网页资源构建通过。已有的大体积构建块提示仍存在，未将其当作运行失败。
- 所有写入在隔离内存数据库完成，没有修改实际题库、学习记录或私人配置；AI工作流使用本机测试服务，本轮未调用真实模型服务。
- 未重新生成APK、Windows发布包，也未执行提交或推送；移动端浏览器布局与资源构建不能替代Android真机验收。

## 后续建议

1. **AI工作台草稿已在同日后续完成。** 推荐组题、普通导入、教材准备与任务分块编辑分别保存草稿，切换前保存，支持恢复和版本冲突另存。操作见[AI工作台草稿](./使用说明书.md#ai工作台草稿)，验证记录见[验收记录](./验收记录.md#2026-10-28-ai工作台草稿)。
2. **统一长文本编辑体验。** 资料编辑已有Markdown工具栏，题目正文、答案和解析可复用同一编辑器，减少格式操作差异，保留纯文本输入的便捷性。
3. **按规模优化加载。** 题集列表目前仍整体获取后在前端筛选分页；题集数量增长到数千份时应改为服务端筛选分页。同时可按功能拆分前端加载块，降低首次进入及移动端的下载开销。此处是扩展建议，本轮没有进行真实大库性能基准测试。
