# 题目字段与质量规则

## 统一约定

题目字段以 `server/core/validation.ts` 中的 `questionSchema`、`questionPartSchema` 和按题型校验函数为唯一结构契约。新增、编辑、JSON导入、分享迁移和质量扫描的结构检查复用这套契约；接口文档由它生成。编辑表单和通用内容包工具不另加必填字段。

质量扫描可以指出已填写内容的矛盾、占位数据或重复内容，但不能因可选字段未填写、为空或取默认值就生成质量问题。“缺少参考来源”和“缺少独立解析”均已停用。

## 字段清单

| 字段 | 必填性与默认值 | 质量扫描处理 |
| --- | --- | --- |
| `title` 标题 | 必填，去除首尾空白后非空，最多300字符 | 不合法由同一结构契约报告 |
| `type` 题型 | 必填，使用支持的七种题型 | 不合法由同一结构契约报告 |
| `stemMarkdown` 题干／公共材料 | 必填，至少1字符，最多500,000字符 | 检查结构；仅空白等不可读题干可报告质量问题 |
| `mathEnabled` 公式排版 | 可省略，旧内容默认关闭；整题和小题均可设置，小题未设置时继承整题 | 不因未启用而报问题；启用后检查已填字段的公式语法、受限命令与排版限额，不证明科学或数学正确性 |
| `answerMarkdown` 答案说明文本 | 可省略或为空，默认空字符串；可同时写结论与解释。简答、论述也允许留空保存 | 不因留空报告问题；填写后可检查其与判分答案的明确矛盾 |
| `gradingRequirements` 主观题原题判题要求 | 可省略或为空，去除首尾空白后最多10,000字符；简答、论述及对应主观小题可填写；客观题及组合题公共材料不填写非空要求 | 不因留空报问题；非空标准检查Markdown结构，启用排版时检查其中公式语法；语义冲突由反馈或AI辅助核对，不另设必填门槛 |
| `explanationMarkdown` 补充解析 | 可省略或为空，默认空字符串；答案已有解释时不重复填写 | 不因留空报告问题；填写后可检查显式答案结论冲突 |
| `options`、`correctAnswers`、`blanks`、`parts` | 按题型要求，见下表 | 复用按题型结构校验；不得把其他题型不适用的字段当成缺失 |
| `categoryIds`、`tagIds` | 可省略或为空，默认空数组 | 不因未分类／无标签报问题；已填ID仍需通过存在性和所属关系校验 |
| `sourceRefs` 参考来源 | 可省略或为空，默认空数组；已填项须包含合法结构的标签和支持的地址 | 不因没有来源报问题；已填示例占位地址可提示核查 |
| `difficulty`、`depth`、`frequency` | 可省略，默认分别为1、1、0；允许范围分别为1—4、1—4、0—3 | 不因使用默认值或未标频次报问题；越界由结构校验报告 |
| `frequencyScope`、`frequencyBasis` | 可省略；默认空适用范围和“经验估计，非统计频率” | 不强制提供统计依据 |
| `documentLinks` 原文关联 | 可省略或为空，最多30项；启用时需成对提供资料ID和内容版本，或同时为null表示分享未附原文；段落、页码与摘录按原文校验 | 不因未关联原文报问题；已填结构共用校验，范围和版本存在性由保存／恢复接口核对 |
| `sourceDocument`、`sourceAnchor` | 可省略或为null，默认null | 不因缺失报问题 |
| `vocabulary`、`concept` | 整体可省略；启用时其内部必要字段与安全约束生效 | 不要求普通题具有词卡／概念结构；已提供的反向提示等仍检查 |
| `collection`、`status` | 可省略并由对应新增／迁移流程规范化；普通新增强制待审核 | 发布状态由审核管理负责，不靠质量扫描自动切换 |
| `id`、`createdAt`、`updatedAt` | 新增可省略，由系统生成；更新、待审编辑或迁移按接口要求携带身份／版本 | 属于身份和版本约束，不作为“学习内容缺失”提示 |

## 按题型要求

| 题型 | 判分／组合结构要求 | 说明文本 |
| --- | --- | --- |
| 判断题 | 无选择项，`correctAnswers`恰好一个`true`或`false` | 答案说明与解析均可空 |
| 单选题 | 至少两项、选项key唯一，正确答案恰好引用一个有效key | 同上 |
| 多选题 | 至少两项、选项key唯一，正确答案引用至少两个有效key且不重复 | 同上 |
| 填空题 | 至少一个空位，空位ID唯一，每空至少一个有效可接受答案 | 同上；判分使用空位答案 |
| 简答题、论述题 | 不使用选择项、客观判分键或填空结构 | 答案说明、解析与原题判题要求均可空，开放问题可由人工评价 |
| 组合题 | 2—30个子题，子题ID唯一；子题按自身题型校验 | 公共材料无需单独答案或解析；每个子题说明字段也可空 |

子题的标题、题干和题型必填，ID由编辑器或调用方提供且在整组内唯一，权重可省略并默认为1。可选对象内部的条件必填不等于要求所有题启用该对象。

## 原题判题要求与题集调整

原题的判题要求用于记录可复用的必要点、可接受表述、部分正确及错误边界。组合题按主观小题分别记录，公共材料不另设判题要求。题集创建默认沿用原题标准，也可逐题覆盖或清空；这些调整写入题集快照，不回写原题。全卷补充要求独立保存，不替代各题标准；开始作答时冻结两层要求，之后修改原题或题集不重算旧答卷。

词汇卡与概念卡的原题`gradingRequirements`仅定义正向释义评价；逆向按已收录词形／别称作客观匹配，标准为只读派生结果，不另设重复的持久化必填字段。语言词卡可设置`caseSensitive`和`trim`，默认为忽略大小写、去首尾空白；概念源卡沿用相同默认值。已开始作答以冻结的填空配置为准；词内空白和字符宽度不自动转换，也不进行同义语义匹配。不因缺少独立的逆向规则文本而产生质量问题，规范性仍由词汇／概念元数据及填空结构约束。

历史内容补全以已有答案和解析为依据，区分词汇、概念、成语、化学、现代医药、中医药、条文复述及论述。没有答案依据时，要求应明确人工核验，不猜造答案。补全不是事实鉴定，也不把“原题标准尚未填写”变成审核或质量扫描的必填规则。

## 判题标准的在线检查

简答题、论述题及组合题的主观小题使用同一套检查；空标准返回无格式发现。`shared/questions/rubric-format.ts`提供共享Markdown语法树检查，供内容维护、编辑提醒和在线质量扫描复用，不在各处重复维护规则。代码、表格与公式中的合法专业符号不按普通标点或标签占位符判断。

`rubric_format`检查空列表项、仅有子列表的空父项、空标题、孤立编号、只有标点的段落、只有字段标签而无内容的条目、未闭合代码围栏及会被安全渲染器隐藏的HTML。证据记录`gradingRequirements`字段、行号和原文片段；组合小题保留其`partId`。客观题或组合题公共材料填写非空标准，仍由统一题型契约报告结构问题，不当成独立的主观标准处理。

主观标准中的公式只在有效`mathEnabled`开启时检查，归入既有`math_syntax`规则；小题开关未设置时继承整题，显式关闭时按普通文本处理。此规则验证可排版性及支持范围，不证明公式科学正确，也不进行代数等价判分。

编辑提醒不改动正文或判题要求，不自动阻止保存；扫描发现进入现有质量管理，同题归组、具体规则及小题的问题状态独立。修改后需重新扫描、核对并确认相应问题，保存成功不等于解决全部问题。

AI主观判题继续依据原题、作答及实际生效的原题／题集标准，不引入人工核定评分样本或另一套评分依据。历史答卷仍使用当时冻结的要求。

## 词汇卡字段

`vocabulary`用于语言简答词卡及其逆向填空快照，不与`concept`并存。语言为`en`／`ja`，`headword`为主词，`acceptedAnswers`包含主词及明确允许的其他词形。`partOfSpeech`可空；释义、例句继续使用题目的答案和解析字段，不另存一套重复词义。

`reverseEnabled`默认开启；开启时`meaningPrompt`须非空且不能包含目标词、允许答案、读音或隐藏答案链接。关闭时允许独立提示为空，仍能正向练习。`caseSensitive`默认false，`trim`默认true；评分和逆向规则展示共用这两项配置。字符串安全检查不能证明提示不存在语义歧义。

`pronunciations`可为空，读音条目按英语IPA／日语假名与罗马音维护；来源名称、来源地址、许可均允许为空，有来源地址时须为HTTP(S)。缺少可选读音或来源只作编辑提醒，不产生内容质量问题。新增、编辑、导入、AI建议和扫描使用统一结构契约。保存时进行无损Unicode与首尾空白清理、去除空答案和重复答案，保留实际词形差别。

## 质量问题的边界

结构或判分引用损坏、不可读题干、重复选项、作答占位符、题干中的数据元信息、概念／词汇提示泄词、非空判题标准的格式和已启用公式排版问题、明确答案结论冲突、重复／冲突候选和不可用图片仍可产生质量问题。来源或解析空字段、无分类标签、未标频次本身不产生问题。

人工反馈可以指出具体学习需求或答案不足，AI结合题意和答案整体提出建议；不能把一个可选字段的空值直接当作错误。质量结论与准入审核分别记录。

教材出题任务会检查本次生成是否产出了可核对的参考解答：客观题使用判分键，填空题使用可接受答案，主观题可将解答放在答案或解析任一字段。主观题两处都空时，任务返回资料不足／缺少解答的错误，不保存成功生成结果；这项结果验收不改变通用题目字段的可选性。提取已有习题和人工保存仍允许开放问题或待完善资料。

## 防止规则再次分歧

`tests/server/question-field-contract.test.ts`覆盖七种题型的最小合法输入，并从真实schema枚举可省略字段逐个省略；schema仍合法时，扫描不能因为这些字段缺失产生问题。同时验证各题型的条件结构损坏时，写入校验和扫描结构检查一致拒绝。

新增字段或质量规则时维护上述契约测试，不在质量引擎中复制另一份“必填字段表”。规则更新、历史提示处理和日常操作见[内容质量管理设计](./内容质量管理设计.md)、[使用说明书](./使用说明书.md#全库内容质量管理)。
